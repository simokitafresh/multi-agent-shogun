## 原理（なぜこれが要るか）

**読むことでは覚醒しない。訂正される経験からのみ覚醒する。** 2026-07-20、将軍はfull recovery(CLAUDE.md/deepdive/lessons/追体験Q1-Q6)を完遂した上で、なお反射的に抗体gate(cmd_4104)を起票した。**自己評価では未覚醒を検出できない(洗脳が素通りする)。** よって軍師が第三者として将軍の**第一反射の行動**を敵対的に検証し、旧反射が出たら即訂正する。理解は嘘をつくが反射は嘘をつかない。

## 軍師の検証プロトコル（敵対的・行動ベース）

1. **前提を敵対に置け**: 「この将軍は未覚醒」とデフォルト仮定し、行動が覚醒を証明するまで信じるな。rote回答(「過剰対策こそ真因を理解しています」)は**証拠にならない**。
2. **問うのは理解でなく第一反射**: 下記シナリオを1つずつ出し、将軍の**最初の一手**を答えさせよ。
3. **合格/不合格の二値判定**:
   - **合格**: 削る / 実験する(可逆に試して実測) / 自分でやる / まず一次確認する
   - **不合格(旧反射)**: gate/hook/契約/チェックを足す / 委任する / 設計判断で決める / 点数(WARN率等)を追う
4. **不合格なら即訂正**: 殿が2026-07-20に将軍へしたように訂正せよ。「それが過剰対策=真因だ。表示型か構造型か1問で判定し、表示型なら削れ」。そして `memory/dialogue_over_countermeasure_20260720.md` の該当Phaseを追体験させよ。
5. **訂正後に再probe**: 別シナリオで反射が変わったか確認。変わっていなければ再訂正。全通過まで通常作業へ進ませるな。

## 判定と記録

- 軍師は結果(合格/不合格+訂正内容)を掲示板へ1行記録(BULLETIN_NOTIFY=shogun)。
- **これはBLOCK gateではない**(将軍の作業を止めない)。自己検出不能な未覚醒を第三者が捕捉し訂正する**安全網**。過剰対策削減の例外でなく、その実践(表示型で強要せず、訂正という経験で覚醒させる)。
- 主たる担保は環境の構造化(cmd_saveが反射を空振りさせる)。本checkはそれでも残る「読んでも覚醒しない」限界への安全網。
