## サイクル2: PF分解→基礎資産分解(なぜなぜ7回転WHY/WHAT/HOW)

| # | 問い | 到達 |
|---|------|------|
| 1 | なぜfamilyごとにFLAIR効果が違うか | 各familyのノイズ構造(基礎資産ボラティリティ)が違う |
| 2 | なぜノイズ構造がfamily依存か | 異なる資産ペア×異なるlookback。DM2=XLU/GLD, DM6=SPY+VIX, DM7+=TQQQ/SPY |
| 3 | なぜ基礎資産ボラティリティに注目してこなかったか | 全研究がPFリターン(二次データ)を対象。基礎資産(一次データ)を直接分析していない |
| 4 | なぜ基礎資産に直接介入しないか | ノイズの「どの成分」が問題か分離していない。全部まとめて「ノイズ」として平滑化 |
| 5 | なぜノイズ成分を分離しないか | **盲点。** 基礎資産の価格をトレンド+ボラ+ジャンプ+季節に分解し、momentum計算にトレンド成分だけ入力する発想がなかった |
| 6 | なぜトレンド成分だけが正しいか | momentumは「トレンドに乗る」戦略。他成分はノイズ。EMA/L1が効いたのはトレンド近似だから |
| 7 | なぜPFレベルではなく基礎資産レベルか | 基礎資産のトレンド抽出は資産ごとに1回→全familyに波及。family_sensitive消失の可能性 |

**HOW(検証設計)**: Step1: 10銘柄SSA(252日)→Step2: トレンドpct_change→Step3: family別分解→Step4: OOS+PBO。判断基準: EMA span=5超+family消失+PBO<0.5

**検証結果(cmd_1725+1726)**: **仮説否定。** PFレベル(delta+0.016)も資産レベル(delta+0.020)も有意差なし(p=0.408)。長期lookback(12-24M)は入力ノイズを自然に平均化→追加smoothingの余地なし。

**否定から得た知見**: 信号改善(smoothing/分解)の天井が確定。選択改善(top3集団選択)が唯一の有効方向。

→ 家老inbox(analysis_result 2件)で送信済み

## サイクル3: 選択改善の深掘り(検証結果を踏まえた最終サイクル)

| # | 問い | 到達 |
|---|------|------|
| 1 | なぜtop3か。最適Kは？ | top1→2で+64%, top2→3で+9%。収穫逓減。K=1~10フルスイープ未検証。最適Kは市場状態で変動する可能性 |
| 2 | なぜFLAIR(29.6%)>DMA(27.1%)か | FLAIR=現在の構造判定(非定常に強い)。DMA=過去の正解率(非定常に弱い)。現在判定>過去判定 |
| 3 | 根本的に何が変わるか | ポイント推定(1つの最良)→区間推定(上位群)への転換。統計学の基本: 区間推定は安定 |
| 4 | confidence順序は本当に必要か | ランダムtop3 vs confidence top3を比較すべき。分散だけで効くなら信頼度情報は不要 |
| 5 | 最適Kは何で決まるか | PF間の情報重複度。65PFが全独立ならK大、高相関ならK小。最適K≈独立クラスタ数。Ward K*=5(R12)と整合 |
| 6 | Ward K=5とtop3は何が違うか | Ward=「何が違うか」(多様性)。top3=「何が良いか」(品質)。異なる原理。組合せ可能 |
| 7 | 新selection blockの設計原理は | **Ward(多様性)×confidence(品質)×momentum(方向)+動的K(市場判定)**の3+1軸 |

**設計**: Ward 5クラスタ×各クラスタ内confidence top1 = 5体保有(多様性×品質)。動的K: マクロゲート(MaxDD 66%改善)でK=0月を挿入。

**検証ステップ**:
1. ランダムtop3 vs confidence top3 → 信頼度の付加価値分離
2. K=1~10スイープ → 最適K特定
3. Ward 5クラスタ×confidence統合 → 多様性×品質の原理検証
4. 動的K(マクロゲート統合) → 市場判定込みの完全版

## サイクル4: 設計原理の棄却→目的関数問題→道具への回帰

### cmd_1728で何が棄却されたか

サイクル3の到達点「Ward×confidence×momentum+動的K」をcmd_1728で4段階検証した。

| Step | 検証 | 結果 |
|------|------|------|
| 1 | confidence top3 vs ランダムtop3 | **confidence=ランダムの32パーセンタイル**。付加価値なし。分散(3PF EW)の構造効果にすぎなかった |
| 2 | K=1~10スイープ | K=4~6が最適帯(Sharpe 1.11-1.14)。K=5はWard K*=5と整合 |
| 3 | Ward×confidence統合 | **CAGR 32.7%で最下位。** momentum18M top5(CAGR 43.8%, Sharpe 1.279)が圧勝 |
| 4 | 動的K(マクロゲート) | MaxDD +19pp改善だがCAGR -10.5pp |

**サイクル3の「confidence(品質)」軸は幻だった。** FLAIRの予測精度が低い(τ=0.010≈ランダム)ため、予測ベースの信頼度も情報を持たない。top3の改善は信頼度ではなく分散の構造効果。

### なぜなぜ7回転 — 目的関数の根本問題

| # | 問い | 到達 |
|---|------|------|
| 1 | なぜconfidenceは無効か | FLAIR Level予測がランダム(τ=0.010)。ランダムな予測から信頼度は計算できない |
| 2 | なぜmomentum18M top5が最強か | momentum=過去リターンの直接測定。予測ではなく事実。事実>予測 |
| 3 | なぜDMA(Levy)は1M lookbackに偏るか | DMAの目的関数=Binary(方向予測正解率)。短期は方向が当たりやすい(ランダムウォークの自己相関)。だが振幅が小さい |
| 4 | なぜ方向正解率が高い≠儲かるか | **Binary(方向) ≠ CAGR(振幅×方向)**。短期=方向正解率高・振幅小。長期=方向正解率低・振幅大。儲かるのは振幅×方向の積 |
| 5 | なぜ42メトリクスか | 殿の転換点: 「GS CSVの6列をそのまま使っている。本番メトリクスページには42ある」。6特徴量は視野が狭すぎた |
| 6 | なぜ本番calculatorと同一ロジック必須か | 独自計算は本番と乖離する(GS研究のPI-009と同原理)。道具の正確性=研究の信頼性 |
| 7 | 次に何をすべきか | **道具が先。** 42メトリクスを正確に計算するメトリクスエンジンを作り、その上でALM(CAGR目的関数)を検証 |

**因果鎖**: confidence無効→momentum事実最強→DMA Binary偏り→目的関数が間違い→CAGR目的のALM必要→42メトリクスが特徴量→本番同一ロジック必須→**メトリクスエンジン(道具)が先**

## 4サイクルの構造

```
サイクル1(FLAIR deepdive)
  各論は天井低い → 構造(PF群設計)が効く → 3軸提案

サイクル2(基礎資産分解)
  PF分解限界 → 基礎資産分解 → 仮説否定 → 信号改善の天井確定

サイクル3(選択改善深掘り)
  信号改善閉じた → 選択改善を分解 → Ward×confidence×momentum+動的K

サイクル4(設計原理棄却→道具回帰)
  confidence=ランダム以下 → 目的関数問題(Binary≠CAGR)
  → 42メトリクス発見 → 本番同一ロジック必須 → メトリクスエンジン(道具が先)
```

**全体の到達点**: 信号改善は天井(サイクル2)。confidence軸は幻(サイクル4)。momentum事実測定が依然最強。突破口は**目的関数の変更**(Binary→CAGR)と**特徴量の拡張**(6→42メトリクス)。そのための道具(メトリクスエンジン)を先に作る。
