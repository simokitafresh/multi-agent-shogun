# EMA最適シグナル実験 — Valeyre (2026) の知見をDM-Signalで検証する AsIs/ToBe 5W1H設計書 v1.0

> **目的**: Valeyre (2026) arXiv:2504.10914 が示した「単一EMA(112営業日/半減期78日)が最適シグナル」が、我らのDM-Signal ETF universeにも当てはまるか実験で検証する。

## §1 AsIs（現状）

### 現行のモメンタム計算
- **追い風(MomentumFilter)**: 固定lookback窓（例: 6ヶ月）の**単純リターン**でPFをランキング。窓の中は等ウェイト、窓の外はゼロ（矩形窓）
- **AbsoluteMomentumFilter**: 同様に固定lookback窓のリターンが閾値を超えるかでリスクオン/オフを判定
- **GS探索空間**: lookback_months をパラメータとしてグリッドサーチ済み。チャンピオンのlookback値は忍法・モード別に異なる

### Valeyreの知見（70先物universe、1990-2023）
- **最適シグナル**: 単一EMA(η=1/112、半減期78日)
- **理論公式**: η_opt = λ√(1 + 2β₀²/λ) で解析的に導出
- **パラメータ**: λ=1/180(平均回帰180営業日)、β₀=0.12(トレンド強度12%)
- **Sharpe**: ARP構築で1.24（EMA 112日）、近傍で緩やか(100日=1.25、150日=1.21)
- **多時間スケール否定**: MACD(3スケール)はSharpe 1.18で単一EMA以下、相関0.99

### ギャップ
- Valeyreのuniverseは**70先物**(株指数/債券/FX/商品)、ポートフォリオ構築は**ARP**(相関逆平方根加重)
- 我らのuniverseは**ETF約20銘柄**、ポートフォリオ構築は**1/N等ウェイト**
- λ(平均回帰速度)とβ₀(トレンド強度)はuniverse固有であり、移植不可(論文自身が指摘)
- **矩形窓 vs EMA**: 同じモメンタム時間スケールでも窓の形状が異なる。EMAが矩形窓より実際に優れるか未検証

## §3 5W1H

### Who（誰が）
- 忍者1名で実行可能（read-only研究スクリプト、本番DB読取のみ）

### What（何を）
- 研究用Pythonスクリプトを作成し、以下を計算する:
  1. 各PFの構成銘柄の日次価格データを本番DBから取得（read-only）
  2. 各銘柄のEMAシグナルを複数の半減期(40/60/78/100/120/150日)で計算
  3. EMAシグナルに基づいて追い風ランキング→月次リバランスシミュレーション
  4. 現行シグナル(α=0、段階的リバランス実験のベースライン)との比較

### Where（どこで）
- ローカル実行。本番DBはread-only接続（段階的リバランス実験と同一パターン）
- SQLiteキャッシュに価格データを保存し、繰り返し実行を高速化

### When（いつ）
- 実験ファースト: まずL0の1体(シン青龍-激攻)で小さく試す
- 結果を見てからL1/L2/L3へ拡大

### Why（なぜ）
- Valeyreの理論的最適性が我らのuniverseにも成立するなら、現行忍法のlookback設計に理論的裏付けが得られる
- 成立しないなら、我らのuniverse固有の最適パラメータを特定できる
- いずれにせよ、現行パイプラインの設計妥当性を定量的に評価できる

### How（どうやって）

#### Phase 0: L0代表1体で小さく試す
- **対象**: シン青龍-激攻 (uuid: f8d70415-24f2-4b1a-a603-d0e86155255a)
- **手順**:
  1. 本番DBからシン青龍の構成銘柄の日次終値を取得（キャッシュ化）
  2. 各銘柄に対してEMA(η=ln(2)/半減期)を計算（半減期: 40/60/78/100/120/150日の6点）
  3. 月初にEMAシグナル値でランキング → top-N選別 → 等ウェイト保有
  4. 月次リターンを計算
  5. 現行シグナル(本番holding_signal)との比較:
     - 同一月で保有銘柄が一致する月数 / 全月数 = **シグナル一致率**
     - CAGR / Sharpe / MaxDD の差分
  6. 半減期ごとのSharpeをプロットし、Valeyreのfig3と比較

- **AC**:
  - AC1: 6半減期 × 1PFの月次リターンテーブルが出力される（production mutation = 0）
  - AC2: 各半減期のCAGR/Sharpe/MaxDDが計算され、現行との差分が記録される
  - AC3: 半減期-Sharpe曲線が出力され、ピーク位置（我らの最適半減期）が特定される

#### Phase 1: 各層1体ずつ拡大（Phase 0の結果を見てから設計）
- **対象候補**:
  - L0: シン青龍-激攻
  - L1: GSチャンピオン忍法PF 1体（追い風系を優先）
  - L2: 奥義PF 1体
  - L3: 秘奥義PF 1体
- L1以降はFoF構造のため、構成PFの保有銘柄をticker×weightに分解してからEMAを適用
- Phase 0の結果で「EMAが明確に劣る」場合はPhase 1を中止し、アイデアとしてとどめる

#### EMA計算の数式
```python
# 半減期 → 平滑化パラメータ
eta = math.log(2) / half_life_days

# EMAシグナル（日次更新）
ema_signal[t] = (1 - eta) * ema_signal[t-1] + eta * daily_return[t]

# 正規化（Valeyre方式: ボラティリティで割る）
ema_vol[t] = sqrt((1 - eta) * ema_vol[t-1]**2 + eta * daily_return[t]**2)
normalized_signal[t] = ema_signal[t] / ema_vol[t]
```
