## §2 二段計測プロトコル

### Tier 1: 劣化検知(wave最終checkpoint)

```
集計期間: 修正後1週間
比較対象: 前週同期間
指標: source:check_id別の累積課税(wall_ms合計)
判定: 前週比で悪化していないこと
```

### Tier 2: ボトルネック特定(弾標的選定)

```
集計期間: 直近24時間
比較対象: なし(絶対値)
指標: 累積課税 + 中央値 + max + 呼出数
判定: TOP N を次弾の標的候補とする
用途: 「今この瞬間の最大の敵」を機械的に特定
```

### 運用

- 各弾のlane最小AC: focused fixture PASS + p50/p95非悪化
- wave最終checkpoint: Tier 1(前週比全量) + Tier 2(直近24h再計測で序列更新)
- Tier 2で依然TOPに残る標的は次弾で再攻撃
