# gate_artifact_map.sh リファクタリング CoDD Spec (事後作成)

## cmd: cmd_1957 (CoDD改善#5)
## 実施者: kotaro

## 問題（ボトルネック関数+計測値）

gate_artifact_map.sh の実行時間 967ms。
ボトルネック: 56行 x 3回の echo | awk = 168サブシェルスポーン。
ループ内で行ごとに echo | awk パイプを3回起動し、さらに sed | sed のパイプ処理。

## 定量プロファイル(実測 before)

| 処理 | 時間 | 根因 |
|------|------|------|
| echo \| awk (56行 x 3回) | 主要ボトルネック | 168サブシェル起動 |
| sed \| sed パイプ | 追加コスト | 追加サブシェル起動 |
| **合計** | **967ms** (3回計測: 895/908/967ms) | ループ内サブプロセス多重起動 |

### サブシェル1回あたりのコスト
- echo + パイプ + awk 起動 = ~5ms/回
- 168回 x ~5ms = ~840ms (推定)

## リファクタリング対象

### R1: ループ内 echo|awk x 168回 → awk 1パス TSV出力 + pure bash 展開

**現状**:
- 56行の入力に対して3回ずつ echo | awk でフィールド抽出
- 168回のサブシェルスポーン
- sed | sed で追加の文字列変換

**改善**:
1. ファイル全体を1回の awk で読み込み、TSV形式で出力
2. while IFS=$'\t' read で受け取り(サブシェル不要)
3. sed | sed を pure bash パラメータ展開(`${var//pattern/replacement}`)に置換

- 期待効果: 168サブシェル → 1回の awk + pure bash = ~800ms削減
- 実績: 967ms → 99ms(90%削減, 9.8x高速化)

## 制約

- テスト: 既存テストなし。bash -n(構文チェック)のみ実施
- API互換（出力形式変更なし）: ゲート出力(アーティファクトマップ)のフォーマット不変
- 凍結ロジック: アーティファクト定義テーブル(56行のマッピング定義)、判定ロジック(存在チェック)
