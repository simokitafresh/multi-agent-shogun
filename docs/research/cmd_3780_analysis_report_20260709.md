# 分析レポート: バンド有り新L0-L3チャンピオン75体のα6堅牢性 — 4視点+レジーム

## 1. 総括(3行)

1. **L3(秘奥義)は時間軸4つの試練(IS・OOS・Expanding・WF)を全指標×全21体で完全通過(正率100%、504/504セル)**。L0→L3の階層が上がるほど堅牢性が単調に強くなる構造が新チャンピオンでも成立
2. レジーム3種は樹形が明確: Bull=CAGR/MRUは全勝だがNHF/MaxDD/AvgUWPのFAILは**SPY基準の定義上の帰結**(Bull期SPYはNHF=1.0/MaxDD=0)で実質弱点ではない。**真の試金石はNeutral**で、ここでもL3だけがCalmar 100%/NHF 81%に到達
3. 全75体がWF CAGRでTQQQを上回る(75/75)。工程4(入替)の堅牢性材料は揃った

## 2. 階層単調性 — 全指標総合正率(本レポートの核心)

| レイヤー | 時間4視点(IS・OOS・Expanding・WF) | レジーム3種(Bull・Neutral・Bear) |
|---------|--------------------------------|-------------------------------|
| L0 | 59.4% (171/288) | 47.2% (102/216) |
| L1 | 86.1% (434/504) | 48.4% (183/378) |
| L2 | 94.6% (477/504) | 57.9% (219/378) |
| **L3** | **100.0% (504/504)** | **73.3% (277/378)** |

- 時間軸もレジームも**単調増加**。FoF階層(BB選別→EW)が下層の弱点(L0のNHF/MaxDD劣位)を吸収する構造は旧体系と同じで、新価格・バンド有りでも再現された
- L0単体のMaxDD正率0%(時間4視点)は仕様的性質: L0はSPYよりDDが深い代わりにCAGR/MRUで圧倒する高リスク部品であり、DD制御は上位層の仕事。L2でMaxDD 57-81%、L3で100%に達する

## 3. 時間軸4つの試練 — L3は完全、L2がほぼ完全

- **L3**: 全6指標×4視点×21体=504セル全部SPY超え。特にWFのCAGR差分+1.2292(SPY 13.4%に対し+123pp)、Calmar差分+9.15
- **L2**: MaxDD(57-81%)以外は全指標100%
- mode別(全レイヤー計)では鉄壁が時間4視点最高90.3%、激攻86.2%、常勝87.8% — 選出目的と整合
- OOSでもL3 CAGR差分+0.9225と、IS(+1.1665)からの減衰が緩い=過適合の兆候が薄い

## 4. レジーム分解 — Bullは定義の罠、Neutralが試金石、Bearは上位層で完成

- **Bull**: CAGR/MRU全レイヤー100%。NHF/MaxDD/AvgUWPの0%はSPY基準がBull期に定義上ほぼ無敵(NHF=1.0/MaxDD=0/AvgUWP=0)になるための機械的FAILで、弱点と読まないこと
- **Neutral**: SPYがNeutral期に強い(NHF 0.82/Calmar 5.82/MaxDD -2.5%)ため最難関。L0/L1はCalmar 0%/23.8%と敗退、**L3のみCalmar 100%・NHF 81%・AvgUWP 66.7%**。ただしL3でもMaxDDは4.8%(1/21、四つ目鉄壁のみ)=SPYのNeutral DD -2.1%より浅く抑えるのは構造的に困難
- **Bear**: L2/L3はCAGR・MaxDD・Calmar全て100%。L3のBear期MaxDDは最悪でも-50.8%(変わり身常勝)、最良-8.3%(加速D鉄壁)でSPY -79.1%を大幅に凌ぐ。**L0のBear CAGR FAIL 6/12の内訳は青龍3モード全滅(-59〜-67%)+白虎2+玄武激攻** — 青龍系はBear局面の部品としては弱いが、上位層の選別が吸収している
