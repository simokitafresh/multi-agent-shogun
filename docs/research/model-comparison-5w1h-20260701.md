# Model Comparison: CLI × Model × Effort 三次元評価

## §1. 三次元の定義

### CLI差(基盤レイヤー)

| 属性 | Claude Code (Anthropic製) | Codex (OpenAI製) |
|------|--------------------------|------------------|
| **対応モデル** | **Sonnet / Opus のみ** | **GPT のみ** |
| クロス使用 | GPTは動かない(別会社・別CLI) | Sonnet/Opusは動かない(別会社・別CLI) |
| Stop hook | 完全対応(`{"decision":"block"}`で即停止) | **無効化**(reason文がプロンプトとして再実行→無限ループ。exit 2でBLOCK代替) |
| PreToolUse/PostToolUse | 完全対応 | 対応(hooks.json経由。共通スクリプト共有) |
| brainwash_check自動強制 | Stop hookで毎ターン強制注入 | daemon/gateで等価補完(構造的に弱い) |
| inbox自動確認 | Stop hookで毎ターン強制確認 | daemon/gateで等価補完 |
| effort設定 | low/high/xhigh | low/medium/high/xhigh |
| context window | **1M**(殿設定で統一) | **1M**(殿設定で統一) |

**CLI差の品質影響(L4 R7-R12実証)**:
- Codex GPTはテンプレートがあれば品質が劇的改善(R7: FP 0% → R8: FP 100%)。テンプレートなしでは崩壊
- Claude Opusはテンプレート有無に関わらず安定(R7/R8ともにFP 100%)
- Claude Sonnetはテンプレートがあっても弱点がフィールド間を移動(R7: 50% → R8: 0%)

### Model一覧

| Model | Provider | **専用CLI** | Context | 特徴 |
|-------|----------|------------|---------|------|
| GPT 5.5 | OpenAI | **Codex のみ** | **1M** (設定で統一) | 最速・最安。テンプレート依存度高 |
| Sonnet 4.6 | Anthropic | **Claude Code のみ** | **1M** (設定で統一) | 速度/品質均衡。定型作業の主力 |
| Sonnet 5 | Anthropic | **Claude Code のみ** | **1M** (設定で統一) | 構造的根因到達。実装・研究向き |
| Opus 4.6 | Anthropic | **Claude Code のみ** | **1M** | 将軍の現設定 |
| Opus 4.8 | Anthropic | **Claude Code のみ** | **1M** | 最新世代。R3-R5で最高品質実証 |

**制約**: GPTはCodex CLIでしか動かない。Sonnet/OpusはClaude Codeでしか動かない。別会社の別製品であり、クロス使用は不可能。CLI×Modelの組み合わせは選択ではなく制約。

**注**: コンテキストサイズは全モデル1Mで統一(effortに依存しない。殿設定)。コンテキストサイズはモデル選択の差別化要因ではない。
