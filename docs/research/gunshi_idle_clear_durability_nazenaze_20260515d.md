## 根因への対策提案

**GP候補**: review-bundleスキルのStep 4に「初遭遇パターン検出」を追加。
review_logヘッダの既知パターン一覧と今回のレビュー判断を突合し、ヘッダに未記載の判断パターンがあれば「新パターン候補: {判断内容}」を表示。
→ 軍師が意識的に環境埋込みを判断できる。

## 因果鎖

```
レビュー速度優先→判断パターン抽出なし(根因)
  → 新パターンが頭の中にだけ残る
  → /clear→パターン消失
  → 次の軍師が同じパターンに初遭遇→判断に時間がかかる
  → レビュー品質/速度が今セッション以下に退行
```
