# なぜなぜ7回: 修行内容の再設計（利他の精神）

## 日付: 2026-05-16
## 起点: 殿指示「自立自走。利他の精神で修行内容を考えよう。なぜなぜ7回」

- 忍者別: hayate 100%, kagemaru 100%, hanzo 77%, kotaro 80%, saizo 87%, tobisaru 80%
- 修行内容: 毎回同一構造（スクリプト改善3点特定→最高1件実装→報告YAML一発PASS）

## なぜなぜ7回

### なぜ1: なぜ修行内容を見直す必要があるのか？
FP率85%で安定。フォーマット修行は天井に近い。残り15%はモデル差やランダム。修行が「報告書フォーマット訓練」に固定化している。

### なぜ2: 本番で忍者が実際に苦しんでいるのは何か？
gate_fire_log本番FAIL原因Top20は全てフォーマット系（gate検出可能）。しかしkaro_workaroundsの非フォーマットWA（verdict_override 9件, stale_ac_contamination 6件, stale_report 5件）と軍師archive FAIL 54件にはフォーマット以外が含まれる。

### なぜ3: フォーマット問題はほぼ解消された。次に鍛えるべき能力は？
gateが検出できない品質問題:
- 実装品質系: AC未達(速度未達/パリティ不一致/成果物不在)
- 判断系: wrong cmd実行、AC定義不一致
- 副作用系: 修正による波及

### なぜ4: なぜ修行はフォーマットしか鍛えていないのか？
設計前提が「gate FAILパターンを学ばせる」。gateはフォーマットを検出する。gateが検出できない能力は修行の射程外に置かれた。

### なぜ5: 忍者に必要だが修行で鍛えられていない能力は？
1. **副作用検出力**: 修正コードの波及先を自力で特定し検証する能力 ← 未修行
2. **偵察力**: 5要件(変更対象/波及先/テスト有無/エッジケース/依存順序)で報告 ← 未修行
3. **テスト設計力**: 何をテストすべきかの判断 ← 未修行
4. **判断力**: ACが曖昧な時のdecision_candidate vs 最善解釈の判断 ← 未修行

### なぜ6: なぜこれらが修行で鍛えられていないか？
根因: **修行が「gate通過訓練」として設計されており「実戦能力訓練」ではない。** gate通過率85%≠実戦能力85%。

### なぜ7: 利他の精神で修行を再設計するなら何を鍛えるか？
利他=忍者の成長が他者の負担を減らす。

**鍛えるべき3能力（利他インパクト順）:**
1. **副作用検出力**: 家老のWAで最も深刻だったverdict_override(9件)の根因は忍者の副作用見落とし。修正→波及→gateは検出不可→家老が手動対処。忍者が副作用を自力検出すれば家老の負担直接減少
2. **偵察力**: 偵察品質が上がれば将軍のcmd品質が上がり、再cmd→再配備の無駄が減る。5要件を実戦で鍛える
3. **テスト設計力**: bats実行するだけでなく「何をテストすべきか」を設計する力。CI RED防止で全員に恩恵

## 修行新設計案（L5: 利他修行）

### L5-A: 副作用検出修行
- シナリオ: 既存スクリプトに意図的にバグを1つ仕込んだブランチを配備。忍者はdiffを読み、副作用を3つ列挙し、検証方法を報告
- 計測: 仕込みバグの検出率+偽陽性率
- 利他効果: verdict_override WA減少

### L5-B: 偵察修行
- シナリオ: 「〇〇機能を変更したい。変更影響を5要件で報告せよ」
- 計測: 5要件の充足率（既知の正解と突合）
- 利他効果: 将軍のcmd品質向上→再cmd削減

### L5-C: テスト設計修行
- シナリオ: 「〇〇スクリプトのテストが不十分。追加すべきテストケースを3つ設計し1つ実装せよ」
- 計測: テストケースの有効性（既存バグ検出力）
- 利他効果: CI RED防止→全員の時間節約

## 自動化ターゲット（deepdive Phase 5）

修行内容の品質計測はフォーマットgateでは不可能。
→ **軍師レビューが品質計測の担い手**。修行報告のlesson_candidateの深度・副作用列挙の網羅性を軍師が4観点でレビューし、定量フィードバックを返す。
→ 長期的には副作用検出力のgateを設計（files_modified × 波及先 × テスト有無の自動突合）

## 因果鎖
gate通過率85%到達→フォーマット修行の天井→修行=gate通過訓練固定→実戦能力(副作用/偵察/テスト)未修行→本番でgateが検出できない品質問題残存→家老WA/将軍再cmd。利他修行(L5)で実戦能力を鍛えれば家老・将軍の負担が構造的に減少=正の複利
