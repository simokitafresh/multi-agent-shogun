入手できればマニュアルが一段正確になるのは、包装の原則ではなく **実測の導線・読者構成・作業時間・公開してよい数字** です。下は、他のLLMにそのまま投げられる質問文です。

## 使い方
- Aは公開ウェブ向け（検索できるLLM）
- Bは本人または会員にしか聞けない
- Cは法務・隣接領域
- 回答は「数字・期間・出典・分からない」を分けさせる

共通前置き（全質問の先頭に付ける）

```
対象は日本語の個人発信「バム（@TokyoJibika / note.com/tokyojibika）」。
目的は、デュアルモメンタムの中身は変えず、届け方のマニュアルを改良すること。
有料本文の中身（個別シグナルや保有銘柄）は不要。
推測で埋めない。不明は不明と書け。
各事実に、観測日と出典URLを付けよ。
```

## A. 公開情報で埋めたい穴

```
1. 2026年9月時点の公開指標を表にせよ。
- Xフォロワー、直近30日の投稿数、中央値の表示・いいね
- noteフォロワー、無料「How to デュアルモメンタム」の本数
- 完全ガイドURLのスキ数・コメント数
- メンバーシップの公開されている人数・プラン名・価格
- dm-signal.com の無料で見える範囲（ログインなしで何が見えるか）
出典を付けよ。有料の中身は書くな。

2. 無料の「次に読む」導線を地図にせよ。
プロフィール、固定ポスト、完全ガイド、How to、ブログ（tokyojibika.blog.jp / hatenablog）、dm-signal の相互リンクを列挙。
初見が迷う分岐を指摘せよ。

3. 日本語検索で「デュアルモメンタム」と出したとき、バム以外に安定して上位に来る無料ページを10個まで。
種別（書籍販売、動画、模倣販売、ツール）で分類。
バムの完全ガイドが勝つ／負ける検索意図を書け。

4. バムの無料記事のうち、Xで繰り返し貼られているものと、一度しか出ないものを分けよ。
「包装済み」と「原材料のまま」の比を概算せよ。

5. 医師×投資の日本語アカウントで、フォロワー1万前後〜20万の例を5つ。

6. Allocate Smartly、Optimal Momentum、Portfolio Visualizer の「無料で分かる説明の型」を抽出。
日本語初見向けに流用できる見出し順だけ書け。戦略の新規提案はするな。
```

## B. 本人にしか聞けない（マニュアルの優先度が変わる）

```
回答は公開してよい範囲だけ。会員の個人情報は不要。

1. 週に発信へ使える実時間は何分カ。診療・当直・家族を除いた枠。
2. 無料読者のうち、医師／会社員／既にDM経験者の概算比。感覚でよいが「分母」を書け。
3. 無料から有料に来る人は、最初にどの記事を読んでいるか。分かれば上位3本。
4. 掲示板やリプで最も多い初回質問を10個。質問文だけ。回答の中身は不要。
5. dm-signal のBasic無料クーポン経由の到達数（月次でよい）。会員数との比。
6. 公開してよいバックテスト数字のホワイトリスト。
期間、ユニバース、CAGR、MaxDD、ベンチマーク。レバなしBasicを優先。
7. 「倍率」「劇薬」「戦国」を入口に残したいか、教材面では下げたいか。本人の選好。
8. メンバーシップを何と定義しているか。教材／ツール／コミュニティ／助言、のどれか。
公開文面と内部運用の差があれば、公開してよい範囲で。
9. 二次利用の許可範囲。要約スレッド、図の転載、引用RT、切り抜き。
10. 届け方を整えたあとの成功指標。フォロワー以外で本人が見るもの。
```

## C. 法務・隣接（マニュアルの禁止事項を硬くする）

```
日本法の一般論。個別案件の法律助言ではない。出典（金融庁監督指針など）を付けよ。

1. 不特定多数向けの無料解説と、会員制の継続課金ツールで、投資助言・代理業の論点はどう分かれるか。
2. 「月次で保有対象を表示するビューワ」を有料会員限定にした場合の、一般的なリスク要因。
3. 公開Xで「公開ユニバースのリターン表」だけ出す場合と、「今月はこれを持て」と出す場合の差。
4. マニュアルが公開面で禁止すべき表現を15個。代替表現を併記。
5. 医師が投資発信するときの職能上の注意（医療広告とは別。混同しやすい点だけ）。
```

## D. 改良後マニュアルへの反映ルール（回答を受け取ったLLMへ）

```
上の回答を、次の箇所にだけ反映せよ。中身の戦略は増やすな。

- §3 入口URLの本数（実測で3つが多ければ2つに減らせ）
- §5 週次枠（本人の可用時間で3枠を2枠に落とせ）
- §6 テンプレの数字スロット（ホワイトリストの数字だけ埋められるように）
- §11 KPI（本人が実際に見られる指標に置換）
- §10 禁止表現（Cのリストで更新）
- 読者ペルソナが医師偏重なら、第一文を「忙しい専門職」に寄せる。一般会社員が多ければ「月1のルール」に寄せる。
新たなチャネル提案は、本人の可用時間が週90分を超える証拠があるときだけ。
```

## いちばん効く3問（時間がないとき）

他のLLMに1回だけ投げるならこれです。

```
1. バムの公開導線で、初見が最初に踏むべき1本はどれか。根拠は被リンクと固定・プロフィールと検索結果。
2. 無料記事の数字で、期間・CAGR・MaxDD・ベンチが揃って再掲してよいセットを3つ抽出。倍率単独のものは除外。
3. 読者が最初に聞く質問を、公開リプと記事コメントから推定して10個。それに対する「有料に誘導せず、既存無料へ返す」一文を作れ。
```

この3つの答えが揃うと、マニュアルは一般論から、**どの記事を週3で回し、どの数字を図に載せ、どの質問を固定ポストで先に潰すか** まで落ちます。
