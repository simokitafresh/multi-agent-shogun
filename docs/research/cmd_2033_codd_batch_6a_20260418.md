# cmd_2033 CoDD Batch 6-A

日時: 2026-04-18
担当: saizo
対象: `scripts/insight_write.sh`, `scripts/gates/gate_shogun_memory.sh`, `scripts/gates/gate_skill_quality.sh`

## 概要

cmd_1951 の A帯スクリプトから 3 本を対象に、起動ごとの高コスト処理を削減した。
方針は共通で、重い YAML 全件ロードと多重 subprocess を減らし、単一走査へ寄せること。

## 計測結果

| script | before | after | 差分 |
|---|---:|---:|---:|
| `scripts/insight_write.sh` | 117ms | 32ms | -72.6% |
| `scripts/gates/gate_shogun_memory.sh` | 22ms | 9ms | -59.1% |
| `scripts/gates/gate_skill_quality.sh` | 355ms | 25ms | -93.0% |

計測方法:
- `insight_write.sh`: `HEAD` 版と作業版を一時ディレクトリへ複製し、同一の空 `queue/insights.yaml` に対する write path を各5回実行
- `gate_shogun_memory.sh`: `HEAD` 版と作業版を同一の実運用ファイル群で各5回実行
- `gate_skill_quality.sh`: `HEAD` 版と作業版を同一の `SKILLS_DIR=$HOME/.claude/skills` で各5回実行
- 集計値は median

## 変更内容

### `scripts/insight_write.sh`

- write path の dedup 判定から `yaml.safe_load` を外し、制御された YAML 形を 1 回走査する軽量パーサへ変更
- resolve path も全件 deserialize をやめ、対象 block のみを書き換える line edit に統一
- 初回作成時の `insights: []` を `insights:` に統一し、append 前の余計な再書込みを削減

### `scripts/gates/gate_shogun_memory.sh`

- `MEMORY.md` の line count, curated date, cmd/PD/ref 抽出を 1 回の走査へ集約
- `completed_changelog.yaml`, `pending_decisions.yaml`, `CLAUDE.md` を都度 grep せず map 化して再利用
- `mcp_sync_staging.yaml` / `mcp_sync_tracker.yaml` の差分判定から PyYAML を外し、軽量 block parser に変更
- テスト用の path override 環境変数を追加

### `scripts/gates/gate_skill_quality.sh`

- skill ごとの `tr + sed + awk + grep + wc` 連打を廃止
- Python 1 プロセスで frontmatter / description / word count / allowed-tools をまとめて走査
- `SKILLS_DIR` override を追加し、unit test から固定 fixture を使えるようにした
