> 2026-04-21 将軍作成 | データ: cmd_2189-2207(WF系), cmd_1844/1877(GS系)

## この記事の読み方

結論から入らない。データを追体験してほしい。

DM-Signalの忍法選出は3層構造: **L0**(パラメータ探索) → **L1**(忍法champion選出) → **L2**(奥義=L1 championの組合せ)。今回の比較では**L0の選出方式だけが異なる**。L1・L2はどちらもGS系。

- **GS系**: L0もGS固定（全期間で最適なパラメータ1つを固定）
- **WF系**: **L0のみWF動的**（ウォークフォワードで期間ごとにL0パラメータを切替）、L1・L2はGS固定

つまり「L0の土台をどう作るか」の違いが、L1 champion選出を経てL2にどう波及するかを見る。同じ忍法、同じビルディングブロック、同じ探索空間。**違うのはL0の1点だけ。**

42体 vs 42体。7忍法×3目的×2系統。L0の選び方で最終成果がどれだけ変わるか。

## §4 4つの試練 × β調整後α6指標

参照手法: [AIが作ったバックテスト戦略、信じていいの?](https://gist.github.com/simokitafresh/e83099b20ad9137fb24e8877f1733e8d)

**β調整の意味:** raw metricsでは市場上昇の恩恵が混入する。β調整はSPYに対するOLS回帰でβ(市場感応度)を推定し、α系列 = strategy_return - β × SPY_return から6指標を算出。**市場の恩恵を除いた純粋なL0選出方式の実力差。**

SPY月次リターン: 本番DB monthly_returns.benchmark_return (175ヶ月, 2011-10〜2026-04)

### 4つの試練

1. **イン・サンプル(IS)**: 全期間でβ推定 + 同じ全期間でα算出。「答えを見ながら解くテスト」
2. **アウト・オブ・サンプル(OOS)**: 前半でβ推定 → β固定 → 後半に適用。「初見のテスト」
3. **拡大窓(Expanding)**: 最初の24ヶ月でβ推定→25ヶ月目1ヶ月のα。毎月β更新、翌月1��月のOOSα積上げ
4. **ウォーク・フォワード(WF)**: IS=24ヶ月固定窓 → OOS=6ヶ月で検証。3ヶ月スライドで繰返し。最も厳しい試練

### β値（市場感応度）

|------|:---:|:---:|
| シンBB | 1.438 | **1.120** |
| ALM-BB | 1.489 | **1.341** |

**WF系のβが低い。** 市場連動が少ない = 市場に頼らず自力でリターンを生む構造。

### α-Calmar（4つの試練を通した中核指標）

検証が厳しくなるほど数字は縮む。縮んだ後に何が残るかが戦略の本当の実力。

## §5 レジーム分析

SPYの月次リターンでレジームを分類（参照gistと同一基準）:
- **Bull**: SPY月次リターン > +2%
- **Bear**: SPY月次リターン < -2%
- **Sideways**: -2% 〜 +2%

β調整後のα月次リターン（市場の恩恵を除いた純粋な超過収益）をレジーム別に集計。

| レジーム | 系統 | α月次平均 GS→WF | α正の月率 GS→WF |
|----------|------|:---:|:---:|
| Bull | シンBB | +3.52%→**+4.79%** | 59%→**65%** |
| Bull | ALM-BB | +4.26%→**+4.48%** | 65%→63% |
| Bear | シンBB | +4.94%→**+5.97%** | 74%→**84%** |
| Bear | ALM-BB | +5.51%→**+6.77%** | 72%→**88%** |
| Sideways | シンBB | +1.81%→**+2.44%** | 68%→**70%** |
| Sideways | ALM-BB | +2.08%→**+3.29%** | 67%→**73%** |

### レジーム分析の読み方

**全6比較でα月次平均がWF勝利。** GS系もWF系も、全レジームでαが正（市場環境に関係なく超過収益を生んでいる）。

**Bearでの差が最も大きい。** GS系+4.94%/+5.51% → WF系+5.97%/+6.77%。市場が下がっている月にこそ、L0 WFの適応力が効く。α正率もBearで最大差（GS 72-74% → WF 84-88%）。市場が-2%以上下がった月の84-88%で、WF系はβ調整後もプラスを出している。

**Sidewaysでα正率がWF優位。** 横ばい相場は戦略の差が出にくいが、WF系は67-68%→70-73%でα正率が改善。小さな差だが、月数が多い（横ばい月は全体の約40%）ため累積効果が大きい。

## §6 総合所見

### 数字が語ること

| 観点 | 結果 |
|------|------|
| Champion勝敗 | WF 40勝 — GS 2勝 (95.2%) |
| 6指標平均α | 全10指標でWF勝利 |
| OOSパフォーマンス | シンBB: WF圧勝。ALM-BB: CAGR微負けだがCalmar勝ち |
| 直近36ヶ月 | 両系統でWF圧勝（Calmar +84%/+56%） |
| Bear耐性 | 勝率はGS優位だがtail riskはWF同等以下 |
| 最大のα | ALM kasoku_diff CAGR +0.449 (119%→164%) |

### なぜL0の違いがL2まで波及するか

GS系はL0で「全期間の最適解」を1つ固定する。市場環境が変わるとL0が最適でなくなり、その上に乗るL1 championもL2も歪む。
WF系はL0で「直近N期間の最適解」に切り替え続ける。L0の土台が市場環境に追随するため、その上のL1 champion選出も環境適応的になる。**L1・L2はどちらもGS固定なのに、L0の土台品質の差がそのまま最終層に伝播する。**

この差がα-Calmarに最も強く現れる。最も厳しいWalkForwardでシンBB α-Calmar 1.67→3.62(+117%)。L0を変えるだけでこれだけ変わる。
