# バム型・届け方マニュアル v4

中身（戦略・有料本文・パラメータ値・上級保有）は変えない。包装・反復・境界・体験導線だけ整える。

観測: 2026-09-02〜03。dm-signal.com 公開面: 2026-09-03。  
本人: 全PFのmetrics公開可。Basic以外の保有・ticker・FoF重みは非公開。二次利用は保有以外可。KPIはエンゲージメント。可用時間は自動化前提で制約にしない。

---

## 0. LLMへの拘束

入力
- スロット（A教材 / B検証・比較 / C体験 / D境界）
- 原材料は無料記事と公開metricsのみ
- 数字はセット（期間またはデータ時点・CAGR・MaxDD・Sharpe・ベンチ）。欠けたら使わない

禁止
- 新規ルール、新規パラメータ
- Basic以外の保有シグナル、構成ticker、FoF重み、ルックバック等の具体値
- 「今これを買え」
- 無敵 / 確実 / 人生が変わる
- 第一文の劇薬・戦国・○倍
- トップ表の「up to / ×N 最良」（とくに Secret）をSNS・記事の主語にすること
- 有料本文の再構成
- フォロワーを目標にする文

許可
- 全PFのmetricsを、最良一本ではなく役割比較で出す
- 層の名前と役割（単純DM / FoF / nested）まで。値は出さない
- 「登録無料・アプリ全機能・見えるPFはBasicのみ」の体験誘導
- 要約スレッド、図転載、引用RT、切り抜き（保有・ticker以外）

成功指標
- 主: 表示、いいね、リポスト、リンククリック
- 副: 完全ガイド到達、dm-signal登録、Basic画面を開いた、境界を復唱できた
- ticker問い合わせが増えたら、showcaseの切り方が失敗

## 1. 公開と非公開

| 人が聞くこと | 出す | 閉じる |
|---|---|---|
| 何をしているか | 相対＋絶対、月1、弱ければ退避 | — |
| 上級は何が違うか | 同じ部品の束ねと検証 | パラメータ値 |
| どのくらい違うか | metricsセット（最良一本にしない） | 構成 |
| アプリで何ができるか | 登録だけで全機能。PFはBasicのみ | 上級シグナル |
| 今月同じに組めるか | 「再現はBasic。登録して画面を開け」 | 上級の保有・ticker・比重 |

境界の定型

```
骨格は公開情報。Basicの保有も公開。
数字（期間・リターン・DD）は出してよい。最良の×Nで釣らない。
登録すればアプリの操作は全部触れる。見えるPFはBasicだけ。
閉じるのは上級の保有とパラメータ値。
```
