# cmd_501 偵察B: 激攻4PFの 3/2誤表示(A) vs 本来3月(B) 損益差分

## 1. 目的
- 対象4PFについて、`A` と `B` の損益差分を定量化する。
- 算定期間:
  - 3/2寄り → 3/2引け
  - 3/2寄り → 最新引け

対象PF:
- 激攻-玄武
- 激攻-青龍
- 激攻-朱雀
- 激攻-白虎

## 2. 算定前提
- `A (誤表示)` = 2026-02-27 の保有構成（3/2時点で誤って参照された想定）
- `B (本来3月)` = 2026-03-02 の保有構成（本来表示される3月ポジション）
- エントリー価格 = 2026-03-02 の open
- 終値:
  - 3/2引け = 2026-03-02 close
  - 最新引け = `prices` テーブル最新 close 日（本実行では 2026-03-02）
- 算式: `Return = Σ( weight_i × (P_end_i / P_start_i - 1) )`
- 差分定義: `Diff = B - A`（正なら B 優位、負なら A 優位）
