無料の導線と既存フォーマットを確認し、中身を変えずに届け方だけ整えるマニュアルに落とします。# バム型発信：中身は固定、届け方だけ整えるマニュアル  
対象：デュアルモメンタムを検証可能な形で出し続けている個人発信（現行はバム @TokyoJibika）  
前提：戦略・検証・有料層の中身は変えない。変えるのは包装、反復、導線、検索可能性だけ。  
想定読者：運用者本人、および同じ制約で下書きを作るLLM。

---

## 0. このマニュアルの使い方（LLM向け）

入力として必ず渡すもの
- 既存の無料記事URLまたは本文
- 「有料に触れてよいか」（原則：触れるのは存在と入口だけ）
- 今日のスロット（後述 A〜E）

出力してよいもの
- X投稿1本＋スレッド案
- note冒頭120字の書き換え
- 固定ポスト／プロフィール文
- 月次1枚図の構成指示

出力してはいけないもの
- 新しい売買ルール
- 新しいパラメータ
- 新しい「○倍」の誇張
- 個別の「今これを買え」
- 有料シグナルの中身の再構成
- 炎上・対立・相互フォロー施策

成功の定義
- 中身の精度を落とさず、初見が「何の人か」「次に何を読めばよいか」を60秒で分かること。
- フォロワー最大化ではない。到達と理解の最大化。

## 1. 変えてはいけない中身（Non-negotiables）

固定する核
1. 相対モメンタム＋絶対モメンタム。出典は Antonacci / GEM / 書籍・論文。
2. 検証可能性。Portfolio Visualizerリンク、期間、ベンチマーク、DDを隠さない。
3. 月1確認という運用負荷。
4. 単純版と上級版の分離。単純版は無料で完結できる。
5. 「保証しない／自己責任／助言ではない」を外さない。
6. メンバー情報の外部転載禁止は維持。

変えてよいのは包装だけ
- 見出しの順序（結論→根拠→リンク）
- 1投稿あたりの情報量
- 図の枚数
- 同じ記事を何回、どの入口から出すか
- プロフィールと固定ポスト
- 投稿時刻と反復

禁止する「中身の改変」
- 倍率を大きく見せるための期間切り出し
- レバを前面に出して入口にする
- 戦国／四神／忍法を初見の第一文にする
- 検証条件を略して「壊れない」「無敵」だけ残す

本人の既存資産（包装の原材料）
- 無料マガジン「How to デュアルモメンタム」
- 完全ガイド  
  https://note.com/tokyojibika/n/n171daa7f92a1
- マガジン  
  https://note.com/tokyojibika/m/mb4377418b422
- 体験用ビューワ dm-signal.com（Basic を無料で見せる導線は既にある）
- 堅牢性レポート（計算日と執行日をずらしても壊れない、等）

## 2. いま届かない理由を、届け方の欠陥として分解する

欠陥は中身ではない。

| 欠陥 | 現象 | 直し方 |
|---|---|---|
| 入口が複数 | 完全ガイド、How to、DM-signal、戦国、不動産コラムが並列 | 常時3点だけ指す |
| 第一文が専門用語 | 浮動小数点、FoF、CPCV | 第一文は「月1回、強い方を持ち、弱い月は退避」 |
| 成果の出し方が広告に見える | 7000倍、劇薬 | 公開では CAGR / MaxDD / 期間 / ベンチマーク |
| 反復がない | 良い記事が1回で終わる | 同一記事を4〜8週間、切り口を変えて再掲 |
| 検索語が内部用語 | シン四神、Ave7 | 検索語は「デュアルモメンタム」「絶対モメンタム」「相対モメンタム」「月次リバランス」 |
| 接触回数が医師スケジュール | 投稿が不規則 | 週3枠を先に決める。中身はストックから切る |

目標フォロワーはKPIにしない。KPIは後述の「理解到達」。

## 3. 情報アーキテクチャ（常時これ以外を増やさない）

公開面は3層だけにする。

L0 入口（60秒）
- 一文定義
- 向く人／向かない人
- 次に読む1本

L1 教材（無料・検証可能）
- 完全ガイド
- How to マガジン
- 公開バックテストと堅牢性記事
- Basic の体験

L2 上級（有料でも欠格にしない。ただし公開では中身を出さない）
- 存在だけ言う。「上級の合成と実務Tipsは有料。無料で型は完結する」

公開で指してよいURLは最大3つ
1. 完全ガイド
2. How to マガジン
3. dm-signal の Basic（体験）

それ以外のURLはスレッド2投稿目以降。プロフィールにもこの3つ以外を増やさない。

プロフィール文の型（中身を変えず、役割だけ明示）

```
耳鼻科医。デュアルモメンタムを検証可能な形で公開。
月1回の確認。上がっている側を持ち、崩れたら退避。
無料：完全ガイド → How to → Basic体験
上級の合成は有料。助言ではない。
```

固定ポストは1本だけ。内容は「定義3行＋向く人＋3リンク＋免責」。戦国の話は固定に置かない。

## 4. 包装ルール（中身固定の変換テーブル）

既存記事を投稿に落とすとき、必ずこの順。

1. 結論（15〜28字）
2. 仕組み（2文。相対と絶対）
3. 数字はセットで出す（期間、CAGR、MaxDD、ベンチマーク）
4. 限界（無敵ではない、継続が本体）
5. 次アクション（読む／見る／体験する、のどれか1つ）
6. 免責1行

数字の出し方
- 単体の倍率禁止を公開面の原則にする。  
  ×「資産556倍」だけ  
  ○「19年、CAGR 17.2%、SPY 10.8%、MaxDD −41% vs −53%」（公開記事にあるなら）
- レバは「上級の選択肢」と書く。入口にしない。
- 未来予測に見える語を使わない（確実、無敵、人生が変わる）。既存に書いてあっても公開再掲では落とす。これは中身の改変ではなく、広告面の抑制。

用語の公開用シノニム（内部用語は2投稿目以降）

| 内部 | 公開第一文 |
|---|---|
| 相対モメンタム | 複数のうち今強い方 |
| 絶対モメンタム | 自分自身が上がっているか。ダメなら退避 |
| Out of market | 債券や短期債への退避 |
| FoF / 忍法 | 複数ルールの束ね（上級） |
| 四神 | 特性の違うファミリー（上級） |
| Ave5/7 | 複数シグナルの平均（上級） |
| CPCV / WF | 過剰最適化を嫌う検証 |

キャラ（殿、戦国）はファン向けB面。A面の初見投稿では使わない。

## 5. 週次オペレーション（医師でも回る上限）

週の枠は3つ。増やさない。

- 枠A 教材再掲（火 or 水、夜）
- 枠B 検証の一切れ（木 or 金）
- 枠C 運用の形（月末 or 月初）

月1だけ増やす
- 枠D 月次の「やり方の確認」（シグナルの中身ではなく、確認手順）
- 枠E 四半期に1回、完全ガイドの更新告知

1枠の作業時間
- 既存記事から切る：15分
- 図1枚：追加15分
- 新規長文：このマニュアルの対象外（中身側）

予約投稿でよい。リアルタイム実況はしない。デュアルモメンタムは月次戦略なので、毎日の相場実況は中身と矛盾する。

## 6. 投稿スロット別テンプレート

### 枠A 教材再掲
目的：ストックを何度も入口にする。

```
デュアルモメンタムは2つだけ見る。
今いちばん強い資産か。その資産は現金より強いか。
弱ければ退避。確認は月1回。

詳細と検証は無料ガイド。
[完全ガイドURL]
助言ではない。過去は未来を保証しない。
```

同じ記事を4週使う切り口
1. 定義
2. インデックスとの違い（リターンではなくDDと確認回数）
3. 向く人（時間がない、ルールで決めたい）
4. 向かない人（毎日売買したい、一発逆転）

### 枠B 検証の一切れ
目的：信頼。数字はセット。

```
「計算日と執行日をずらすと壊れるのでは」への公開検証。
条件を同時にずらしても、この設定では形が残った。
期間と前提は記事に全部ある。

[該当無料記事]
重要なのはカーブの形より、前提を公開していること。
```

禁止：検証の一部だけ切って「すげえよ」で終わる。既存口調は本人の地だが、再掲では根拠リンク必須。

### 枠C 運用の形
目的：負荷の低さを身体で分からせる。

```
必要な作業は月1回。
1. 判定日のリターンを見る
2. 相対の勝者を取る
3. 絶対がダメなら退避先
所要は十数分。

Basicで仕組みだけ体験できる。
[dm-signal]
中身の売買指示ではない。自分で再現できるかが本体。
```

### 枠D 月次
出してよいもの
- 「今月も手順は同じ。確認は月1」
- 公開できるなら、公開ユニバースのリターン表（SPY / VEU / SGOV のような教科書セット）
- 「これはGEMの説明用であり、売買指示ではない」

出してはいけないもの
- 有料ファミリーの今月の保有
- 「スタンダードは今月+5.53%」を集客文の主語にする

公開してよい月次の主語は「手順」と「公開データの説明」。成績の主語は有料側に残す。

## 7. note側の届け方（記事は増やさず、冒頭だけ整える）

既存記事の本文は触らなくてよい。触るのは
- タイトル
- リード120字
- 一番上の「次に読む」
- 見出しの最初の1個

タイトル規則
- 検索語を前に置く  
  ○ デュアルモメンタムは計算日をずらしても壊れない  
  × 第三弾のレポートです
- 数字を入れるなら期間と対象を同時に入れる

リードの型

```
結論1文。
対象（忙しい人／月1で決めたい人）。
この記事で分かること3点。
先に読むべき1本（完全ガイド）。
```

マガジンのピンは1本のまま維持（完全ガイド）。新記事ができてもピンを戦国に変えない。

## 8. 図の規格（1枚で完結）

公開図は3種類だけ。

図1 仕組み
- 箱A 相対：US vs 非US
- 箱B 絶対：勝者 vs 短期債
- 箱C 保有 or 退避
- 注記：月次、12か月が基本形

図2 比較
- 2本の累積と MaxDD だけ
- 期間を図内に書く
- 「過去。費用・税・約定は別」

図3 月次チェックリスト
- 見る指標
- 決めること
- 触らないこと（日々のニュース）

図に書いてはいけない
- 有料シグナル名の一覧を集客用に並べること
- 倍率だけ大きい数字

## 10. 法務・信頼の包装（届け方に含む）

公開を増やすほど、助言に見える面も増える。届け方の整備に、規制面の抑制を含める。これは中身を弱めるためではなく、継続可能にするため。

公開面の原則
- 教育・検証・再現手順に寄せる
- 「今これを買え」を書かない
- 有料クローズドで個別タイミングを厚くするほど、登録要否の論点が出る。公開マニュアル側では「無料は誰でも読める教材」「有料はコミュニティとツールであり助言契約ではない」と本人が既に書いている線を崩さない
- 個別質問への公開返信は一般論に戻す。「あなたの口座ではこうせよ」は書かない

免責の最短形（毎スレッド末尾で可）

```
教育目的。特定銘柄の推奨ではない。過去の検証は将来を保証しない。
```

## 11. KPI（フォロワーを捨て、理解到達を見る）

週次で見る（15分）
- 完全ガイドのスキ・ビュー
- How to マガジンのフォロー増分
- dm-signal Basic の到達（公開できる範囲）
- 固定ポストのリンククリック
- 「次に何を読めばいいか」質問の減少

見てよいが最適化しない
- フォロワー
- いいね
- 「1位」言及

赤信号
- 公開投稿の主語が倍率と月次成績になった
- 無料記事を読まずに有料へ飛ぶ質問が増えた
- 検証リンクなしの断言が増えた

青信号
- 「月1で強い方、ダメなら退避」を他人が説明できるようになった
- PVリンクを自分で開いた報告
- 戦国用語を使わずに質問が来る

現実的な到達（中身固定の場合）
- 12か月で「DMを日本語で調べた人が必ず踏む無料ハブ」になる方が、フォロワー2万より価値がある
- フォロワーは副産物。目安は以前の整理どおり、包装だけなら1.5〜4万が上限付近。目標にしない

## 12. LLMへの実装プロンプト

システムに貼る文

```
あなたは包装担当である。投資戦略の中身・パラメータ・新規シグナルを提案しない。
入力された既存無料記事だけを使う。
出力は日本語。構成は「結論→仕組み2文→数字は期間/CAGR/DD/ベンチをセット→限界→次アクション1つ→免責」。
内部用語（四神、忍法、Ave、劇薬、FoF）は初投稿に出さない。
倍率単独、今これを買え、保証、無敵、を出さない。
リンクは指定された3つのうち必要なものだけ。
有料の中身を推測して埋めない。
```

ユーザーが渡す文

```
スロット：A/B/C/D
原材料URL：
使ってよい数字：（記事にあるものだけ箇条書き）
今回の切り口：定義 / 検証 / 負荷 / 向かない人
禁止：有料シグナル名を主語にしない
```

品質チェック（生成後にLLMが自分で見る）
- [ ] 第一文でデュアルモメンタムの2部品が分かるか
- [ ] 数字が単独倍率になっていないか
- [ ] 次に読む先が1つか
- [ ] 新しいルールを足していないか
- [ ] 助言に読める命令形がないか

## 14. 他LLMが間違えやすい点

- 「もっと簡単に」を「レバと倍率で簡単に見せる」と解釈する → 不可。簡単にする対象は文の順序だけ。
- 「エンゲージメント」を目的化する → 不可。目的は再現可能な理解。
- 有料があることを隠す／逆に有料を前面にする → 両方不可。分離して併記する。
- 本人の口調（大阪弁混じり、戦国）を全投稿に複製する → B面だけ。A面は標準語の短文。
- Antonacciを消してオリジナル発明に見せる → 不可。書籍部品は出典を残す。模倣ではない。

---

要約すると、必要なものは新コンテンツではなく、**入口を3つに固定し、既存の検証を「結論→仕組み→セット数字→限界→次の1手」で週3回出し直す装置**である。それを守れば中身は同じまま、探し当て可能性だけが上がる。
