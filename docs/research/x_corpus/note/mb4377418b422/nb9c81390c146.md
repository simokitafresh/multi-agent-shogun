勝てるはずの戦略で負ける人がいる
期待値がプラスの戦略を持っていれば、長期的には資産が増える。
多くの投資家はそう考えます。
しかし現実には、期待値がプラスでも資産が減り続ける経路は存在します。戦略が本来の優位性を発揮する前に、投資家が不安に耐えられず運用をやめることもあります。
やめた瞬間、バックテスト上の期待値は意味を失います。
投資戦略には、少なくとも二つの性能があります。
長期的に利益を生む能力
その利益が実現するまで継続できる能力
どれほど優秀な戦略でも、実際に続けられなければエッジは実現しません。
重要なのは、期待値やCAGR、Sharpe比だけではありません。
その戦略を必要な期間だけ続けられるか。
これも独立して評価すべき性能です。
期待値と実際の資産成長は違う
100万円を投資し、ある月に50％上昇し、翌月に50％下落したとします。
資産は次のように変化します。
100万円
→ 150万円
→ 75万円
月次リターンの算術平均はゼロです。
[
\frac{50%+(-50%)}{2}=0%
]
しかし、実際の資産は25％減っています。
リターンは足し算ではなく、資産額に対して乗算されるからです。
この算術平均リターンと幾何平均リターンの差が、ボラティリティドラッグです。
概算では、期待対数成長率は次のように表されます。
[
E[\log(1+r)]
\approx
E[r]-\frac{1}{2}\operatorname{Var}(r)
]
平均リターンが同じでも、変動が大きいほど複利成長率は低下しやすい。
ただし、ボラティリティが高いこと自体が悪いわけではありません。
上方向への大きな変動と、下方向への大きな変動では意味が違います。
そのため、継続可能性を評価するには、平均と分散だけでなく、分布の歪み、テール、連敗期間まで見る必要があります。
継続可能性を測る5つの指標
DM-Signalでは、戦略の収益性だけでなく、投資家が現実にその戦略を継続できるかを評価するため、次の5指標を本番環境で提供しています。
なお、メンバーシップで提供しているデュアルモメンタム戦略は、すべて月次リバランスです。
したがって、以下の指標も同じ月次リターン系列を基準に比較できます。
1. ボラティリティドラッグ（VDrag）
VDragは、算術平均リターンと幾何平均リターンの差です。
[
\mathrm{VDrag}
\bar{r}_{\mathrm{arithmetic}}
r_{\mathrm{geometric}}
]
この値が大きいほど、見かけの平均リターンに対して、実際の複利成長率が低いことを意味します。
VDragを見ることで、次のような戦略を識別しやすくなります。
平均リターンは高いが資産が増えにくい
レバレッジによって複利効率が悪化している
同じCAGRを得るために過大な変動を負担している
VDragは、「平均的には勝っているのに、なぜ資産が思うように増えないのか」を可視化する指標です。
2. 歪度（Skewness）
歪度は、リターン分布の左右の非対称性を示します。
正の歪度を持つ戦略は、
小さな損失が比較的多い
ときどき大きな利益が出る
という形になりやすい。
負の歪度を持つ戦略は、
小さな利益が頻繁に出る
まれに大きな損失が出る
という形になりやすい。
モメンタムやトレンドフォローは、ダマシによる小さな損失を繰り返しながら、大きなトレンドを捕捉することで、正の歪度を持ちやすい戦略です。
一方、ショートボラティリティや過剰なキャリー、損失を先送りするナンピン戦略は、負の歪度を持ちやすい。
ただし、正の歪度だから安全とは限りません。
歪度は、最大ドローダウンやExpected Shortfallなどの下方リスク指標と併せて評価する必要があります。
3. 尖度（Kurtosis）
尖度は、リターン分布のテールの厚さを示します。
尖度が高い戦略では、極端な上昇や下落が起きやすくなります。
特にレバレッジ戦略では、通常時の値動きだけでなく、テールも拡大しやすい。
尖度を見ることで、平均と標準偏差だけでは捉えにくい、極端な月次変動の起こりやすさを確認できます。
ただし、尖度は上方向と下方向を区別しません。
大きな上昇が多い戦略も、大きな暴落が多い戦略も、高い尖度を示す可能性があります。
そのため、尖度は歪度や下方リスク指標と組み合わせて使います。
4. 最低継続期間（MinMo）
MinMoは、その戦略のアルファや優位性を評価するために必要となる最小月数です。
例えば、MinMoが36であれば、通常の月次変動と戦略の真の優位性を区別するには、少なくとも3年程度の観測が必要であることを示します。
12か月成績が悪かったからといって、直ちに戦略が壊れたとは限りません。
単なる統計的変動の範囲かもしれないからです。
MinMoは、
通常の不調だけを理由に戦略を評価するには、何か月程度必要か
を示す目安です。
ただし、戦略の前提が崩れた場合や、過去の想定を大きく超える損失が発生した場合まで、機械的に継続すべきという意味ではありません。
5. 最大連敗期間（MaxConsecLoss）
MaxConsecLossは、月次リターンが連続してマイナスとなった最長月数です。
例えば、
最大3か月連続で損失
最大8か月連続で損失
最大14か月連続で損失
では、心理的な負荷が大きく異なります。
最大ドローダウンが同じでも、一度に急落して短期間で回復する戦略と、毎月少しずつ負け続ける戦略では、投資体験が違います。
MaxConsecLossを事前に把握しておけば、
「過去には最大で何か月連続の損失があったか」
を確認できます。
これは、最悪の損失額ではなく、どれだけ長く「負け続けている感覚」に耐える必要があるかを示す指標です。
続けられる戦略は人によって違う
継続可能性は、戦略だけでは決まりません。
同じ戦略でも、次の条件によって続けやすさは変わります。
投資期間
最大許容損失
生活資金との分離
レバレッジの有無
収入の安定性
損失への心理的反応
他資産との組み合わせ
重要なのは、バックテスト成績が最も高い戦略を選ぶことではありません。
自分が継続できる範囲で、最も高いエッジを持つ戦略を選ぶことです。
例えば、正の歪度を持つ戦略は損小利大になりやすい一方、小さな損失が何度も続くため、高い勝率を求める投資家には苦痛かもしれません。
逆に、高勝率でも負の歪度を持つ戦略は、普段は快適でも、まれな大損失に耐えられない可能性があります。
戦略の優劣だけでなく、自分との適合性を見る必要があります。
想定内の不調と戦略崩壊を区別する
「続けることが重要」という言葉は、どのような損失でも耐え続けるという意味ではありません。
再評価が必要なのは、例えば次のような場合です。
ドローダウンが過去の想定を大きく超えた
取引費用が期待収益を上回った
市場制度や執行条件が変わった
シグナルの前提となるデータ構造が変わった
実運用成績がバックテストから大きく乖離した
バグや先読みバイアスが判明した
一方、現在の連敗やUnderwater Periodが過去にも繰り返し発生している範囲なら、通常変動である可能性があります。
これらの指標は、投資家を無条件に安心させるためのものではありません。
現在の不調が想定内か、想定外かを判断するための道具です。

結論
期待値がプラスであることは、投資戦略にとって必要です。
しかし、それだけでは十分ではありません。
エッジを実際の利益へ変えるには、不調期を通過し、必要な期間だけ戦略を継続する必要があります。
そのためには、CAGRやSharpe比だけでなく、次の性質を見る必要があります。
平均リターンと複利成長率の乖離
リターン分布の歪み
テールの厚さ
評価に必要な月数
連続損失の長さ
投資で重要なのは、単に優秀な戦略を見つけることではありません。
その優秀さが実現するまで、自分が続けられる戦略を選ぶことです。
継続は精神論ではありません。
