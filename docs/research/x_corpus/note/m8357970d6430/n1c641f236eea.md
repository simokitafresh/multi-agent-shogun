# Claude Code Action 高度な設定とカスタマイズ

<!-- key=n1c641f236eea publish_at=2025-06-01T22:30:30.000+09:00 price=0 full=True like=7 -->

少し高度な設定とカスタマイズについてまとめました。

セキュリティ設定
allowed_toolsで実行可能コマンドを制限
claude.ymlでClaudeが使用できるツールを制限します。これによりセキュリティリスクを軽減できます。
基本的なツール：
ツール名 説明 View ファイルの閲覧 Edit ファイルの編集 Write 新規ファイル作成 GlobTool ファイルパターン検索 GrepTool テキスト検索 BatchTool 複数ファイル操作
設定例：
# Python開発用の安全な設定
allowed_tools: "View,Edit,Write,GlobTool,GrepTool,Bash(python),Bash(pip)"

# Git操作のみ許可
allowed_tools: "Bash(git:*),View"

# テスト実行も含む
allowed_tools: "View,Edit,Write,Bash(python),Bash(pip),Bash(pytest)"
ワークフロー権限の最小化
permissions:
  contents: write      # ファイルの読み書き
  pull-requests: write # PR作成・更新
  issues: write        # Issue操作
  id-token: write      # OIDC認証
  # 以下は付与しない
  # actions: write     # ワークフロー変更は不要
  # packages: write    # パッケージ公開は不要
自動化の設定
PRの自動コードレビュー
PRが作成されたら自動的にコードレビューを実行する設定：
name: Auto Code Review

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  auto-review:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
      
      - name: Run Code Review with Claude
        uses: grll/claude-code-base-action@main
        with:
          prompt: |
            PRの変更内容をレビューしてください。
            以下の観点で確認をお願いします：
            1. PEP8準拠
            2. 型ヒントの適切な使用
            3. エラーハンドリング
            4. セキュリティの問題
            5. パフォーマンスの改善余地
          allowed_tools: "View,GlobTool,GrepTool"
          timeout_minutes: "20"
          use_oauth: 'true'
          claude_access_token: ${{ secrets.CLAUDE_ACCESS_TOKEN }}
          claude_refresh_token: ${{ secrets.CLAUDE_REFRESH_TOKEN }}
          claude_expires_at: ${{ secrets.CLAUDE_EXPIRES_AT }}
カスタムインストラクションの追加
プロジェクト固有の指示を設定：
custom_instructions: |
  以下のコーディング規約に従ってください：
  - PEP8完全準拠
  - 型ヒントは必須（Python 3.9+ syntax）
  - docstringはGoogle形式
  - 変数名は英語、コメントは日本語
  - エラーハンドリングは必ず実装

メンテナンス
Claude Code Actionの無効化
ワークフローファイルを削除：
# 🐧Ubuntu（WSL2）で実行： rm .github/workflows/claude.yml git add . git commit -m "Remove Claude Code Action" git push

GitHubのSecretsを削除：
Settings → Secrets → 各トークンの削除

WSL2の完全削除（必要な場合のみ）
警告： WSL2内のすべてのデータが削除されます。
# 🪟Windows PowerShell（管理者権限）で実行：

# バックアップを取る
wsl --export Ubuntu backup.tar

# Ubuntuを削除
wsl --unregister Ubuntu

# WSL2を完全停止
wsl --shutdown
高度なデバッグ
実行ログの詳細分析
- name: Process Claude Output
  if: steps.claude-task.outputs.conclusion == 'success'
  run: |
    # 実行ログを解析
    cat ${{ steps.claude-task.outputs.execution_file }} | jq '.'
    
    # 最後のメッセージを抽出
    cat ${{ steps.claude-task.outputs.execution_file }} | \
      jq -r '.[] | select(.role == "assistant") | .content' | \
      tail -n 1 > claude_output.txt
