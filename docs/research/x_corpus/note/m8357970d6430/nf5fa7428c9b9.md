# ビジネス童貞の新規開業医師達はマーケティングの基本を知らないまま戦ってはいけない。

<!-- key=nf5fa7428c9b9 publish_at=2025-02-22T17:10:02.000+09:00 price=1500 full=True like=13 -->

Xなどのソーシャルネットワークサービスを見ていると、スタートダッシュから成功しているウハクリばかりに思えるはずです。年商数億当たり前、連日患者数100人オーバー、さて本当でしょうか？

はい、本当です。

しかしそうではない先生方も数多くいるはずです。
先日こんなアンケートをしてみました。
医師一人あたりの売上1億円以上は、上位何％だと思うか？医師一人あたりの売上が1億円を越すクリニックは上位10％であると思う先生は50.7%（有効回答数）多かったです。上位30％までに入ると思う先生を合わせると90.4％にも及びました。このアンケートが示唆するところは年商1億円未満のクリニックの方が多数派ではないかという事実です。

「うちは金儲け主義じゃないから……」そんな言い訳を自分にしていませんか？開業医は診察だけが仕事ではありません。経営も開業医として必要不可欠な仕事です。そして経営の中にはマーケティングも含まれます。
マーケティングという単語を聞くと、まるで別の世界の話のように感じる先生も多いのではないでしょうか。うちの親父もそういう「お医者様」でした。もちろん患者数が300人を越す「良いお医者様」ではあったと思います。しかしそれは人口ボーナス期の紛れであった一面も無視できません。
現代は親父の時代とは全く異なります。例えば僕は東京23区内のビル診で非承継として開業しています。（親父のクリニックは継ぎませんでした。余談ですが相続も放棄しています。）
半径1kmに競合4件、2kmで9件（東京では隣の駅まで2kmもないです。）耳鼻科と競合しやすい小児科も10件以上ある環境で働いています。
また僕は診察が遅く、開業から10年以上経った今でも時間辺り15人すら診ることは出来ません。（それでもDXで随分と速くなりましたが）今日も土曜の午前診察が終わったのが15時40分です。9時過ぎには6時間待ちとなりました。
ありがたいことに開業初日から損益分岐点を下回ったことは1日たりともありません。なぜでしょうか？僕は医師よりも商売人としてのキャリアが10年以上長いからです。商売人の常識は幼少時から骨身に染みていたおかげです。
よく医師は常識が足りないと揶揄されますが、開業医となるならばマーケティングの基本は抑えておきたいものですね。僕ら医師は圧倒的に学習能力が高いです。そして学んだことを即実戦に応用し、変わり続ける状況に適応する能力にも優れています。
今回は1980年代に出版されて世界中でベストセラーとなり、日本でも2000年代初めに邦訳されている、ジェイ・エイブラハムの「ハイパワー・マーケティング」を教科書にマーケティングの基本を学びましょう。時代によりツールは進化しますが根底に流れるものは変わりません。（残念ながら書籍は絶盤であり一般的な流通ルートでは邦訳版の入手は現状困難です）
すでに開業している先生はもちろん、これから開業する先生や、勤務医の先生方にも役に立つと考えています！
