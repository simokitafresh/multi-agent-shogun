# ベースアップ加算のほにゃほにゃ雑記

<!-- key=n495e1751f0fc publish_at=2026-05-09T16:20:35.000+09:00 price=0 full=True like=7 -->

ブログ調で雑記、推敲もタイポも気にせず書いて出し。特にお得な情報はありません
ベースアップ加算の話。昨日ドクターチャートの先生方のクラブハウスにおじゃました。とても勉強になったので、開業医や開業予定の先生方はコンサルの前にドクターチャートにぜひご参加を。お勧めです。
で、話を戻すんけどベースアップ加算、ざっくりいうとスタッフの給与を増やすなら、初診料と再診料に上乗せしていいよって話。まあ具体的な点数とかは今回は雑記なのでとばす。
計算したところ当院だとざっくり月25万くらいの増収になる予定。年間だと300万円。デカいよね、ただそれはスタッフの給与に回すものでクリニックの利益には関係ないし、ましてや院長の収入にはなんの関係も無い。
もちろん働いてくれているスタッフへプラスになるのはいいけどね。今回は金の話をしよう。
年間300万スタッフの給与を増やすと、クリニック負担分の社会保険料も上がる。ざっくり15％余分に消えるって事だ。なんか16.5%引いてもいいらしいけど（細かな話はしません）なんにせよトントンだよね。
つまりクリニックの経営には直接的にはなんの意味もない。間接的にはスタッフの給与が上がるけど、加算がなくなったらどうすんの？仮に来年、再来年としばらくは増えるとしてもだよ？パイが限られている以上は他のどっかを減らすはず。
それなら加算とらずに俺の給与を300万減らして、スタッフの給与を増やす方が楽でいいなあと思ったり。どうせ半分は税金だ。院長の報酬を300万円減らしても手取りベースで考えれば半分の150万、月で言えば12万5000円。デカいけど4月5月はデュアルモメンタムのおかげで1000ヶ月分以上お金増えた。まあそれはどうでもいいか。
いったいぜんたい多くのクリニックではどれくらいの患者数なんだろう？うちは耳鼻科だから比較的に多い。予約は100人制限をしているから、ならすと再診80人＋新患初診20人ってとこ。田舎なら医師一人で2倍みてるかも知れないけどそれでも年間600万。内科だと医師一人あたりの診察人数が100人/日を10年平均で出せるところはレアだろう。セコく必死に再診を初再診に変えて初診料をとりにいっても月に+50万ですらそう出せないんじゃないかな？
なんとなく誰も彼も税引後の手残りキャッシュ計算していないというか、自院の患者数でのガチ計算を隠しているように感じる。
税引後のクリニックに残る利益はいくらなんだい？それが知りたいよなあ。
もちろん医師一人あたり平均300人みてベースアップ加算で年間2000万は増収するみたいなスーパーマンならべつ。普通のウハクリレベルですらやって得はない。けど、今後の損につながらないためにナンセンスで面倒いけどやるしかないて感じかなあ。
専門医と一緒でとったから何が変わるといえば変わらない（ここではお金の話しかしていないので保険診療点数的に専門医だから加算がつくことがないという話。一部の診療科では加算というより非専門医は減算はすでにあるけどね）
ということで結論として面倒いけど、やる。でもやりたくないンゴ。
社労士と会計士の先生達に丸投げで、トータルのコストから見れば経営的に短期ではマイナス、長期ではリスク激高（そうは言っても上げた給与を下げるのは難しい）のルビコン川を渡る覚悟がいるね。
特にオチもまとめも無しでした。
