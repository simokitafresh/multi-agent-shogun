# 稼げるレアリティーとはなにか？

<!-- key=n78d72d168756 publish_at=2026-01-01T19:57:43.000+09:00 price=0 full=True like=13 -->

人は何をもって「本物」と感じるのか
問いの立て方を変えよう。
「本物とは何か？」という問いに正解はない。
だから問いを変える。「人は何をもって本物と感じるか？」という感情そのものを考察の対象にする。
本物とは「他との違いが著しい状態」
人が本物と感じる根底には、客観性がある。客観性とは対比によって生まれる。他との違いを認識することで、人は本物を判別する。
本物＝善ではない点に注意が必要だ。本物のクズ、本物のバカ、本物の悪も存在する。本物とは単に「他との違いが著しいもの」を指す。
ストーリーが本物を作る
仏像を例に考えてみる。本物の仏像と偽物の仏像を分ける決定的な要因は何か。
答えは、その像に関わってきた人々の感情の量だ。
"仏"像であれば、仏である以上、僧侶による儀式通過は必須かもしれない。しかし"像"としてはどうか。
長年にわたり信仰の対象になっている

権威のある博物館に飾られている

専門家が本物と判断した

歴史やいわれがある

名のある人物のコレクションだった

上記の要素はすべて"像"そのものとは無関係な装飾にすぎない。装飾の正体はストーリーだ。
時間がストーリーを積み上げる
私は様々なコレクションを保有している。最も長年にわたり資金を投入してきたのは博物誌の図譜だ。
図譜の中にはリトグラフ等の当時としては大量生産されたものもある。100年以上にわたり使われていた元図もある。現在では300〜500年前の図譜は貴重な"本物"として扱われる。
では当時はどうだったか。確かに当時でも裕福な人向けの"商品"だったことは間違いない。しかし教科書のいたずら書きのような落書きが描かれている図譜も存在する。
当時の日常品が、時間の経過とともにストーリーを纏い、本物へと変化した。
レアリティは他者の認知で形成される
漫画家の描いた生原稿と出版された漫画本、どちらが本物だろうか。内容は同一だ。ストーリー展開も同じだ。
両者を分けるのはレアリティだ。
レアリティとは他者の認知によって形成される。数が少ないだけでは単に人気がないものであり、レアではない。多くの人が「欲しい」と認知し、かつ数が少ない状態がレアリティを生む。
投資における本物はリターンで判断される
投資の世界にも様々なレジェンド投資家がいる。過去には世界は閉ざされ、アービトラージ機会もたくさんあった。名著といわれる本を読んで知識を得ることは有益だ。
では本物の投資スタイルとは何か。
例えば1920年代〜1990年代に圧倒的なパフォーマンスを出した投資スタイルAがあったとする。しかし2000年代に入ってからのパフォーマンスは最悪だ。
投資スタイルAは1980年には"本物"だった。では現在も本物か。
投資において本物とは、現時点における実績があるものを指す。現在パフォーマンスが高いものが本物であり、現在のパフォーマンスが悪いものは"昔々本物だった"にすぎない。
本物かどうかは現在のリターンを元に判断される。ルックバック期間を揃えて判断する必要がある。私は3年ローリングリターンを愛用している。
本物を構成する3つの要素
人が本物と感じるための主要素は3つある。
ストーリー は、対象に関わってきた人々の感情の蓄積だ。歴史、いわれ、権威ある評価がストーリーを形成する。
レアリティ は、他者の認知と希少性の掛け合わせだ。多くの人が欲しがり、かつ数が少ない状態がレアリティを生む。
リターン は、現時点での実績だ。過去ではなく今のパフォーマンスが本物かどうかを決める。
3つの要素の総合力で本物は判断される。
インチキ臭いプロフィールの正体
よくあるインチキ臭いプロフィールを分解してみる。
投資家版の例：
20代からヘッジファンドで活躍したトレーダー（ストーリー）

現在のコミュニティ参加者は10万人超え（レアリティ）

独立して近年は500％以上の利益を挙げた（リターン）

どこかで見たことがありそうな構成だ。
外科系医師版の例：
一流病院勤務を経て海外留学、ベストドクターに選出（ストーリー）

他病院にも出張手術を依頼され精力的に活躍（レアリティ）

半年以上先まで手術予約があり延べ3万人の手術実績（リターン）

同じ構造で作られている。3要素を揃えれば本物らしく見えてしまう。
本当の本物は3要素なしでもグッとくる
ここまでで本物と人が感じる理由は説明できた。
しかし最後に1つ補足がある。
本当の本物は上記の3要素がなくてもグッとくる。私と奥さんがふとこれいいねと同時にグッときたものは、大抵その店で一番高いものだ。言語化できない引きつけられる感覚がある。
恐ろしいことに、ふと気になって角を曲がってのぞき込むと、そこに本物が待っていることがある。棚の片隅の裏の方に隠されていることもある。
購入を決めてお金を支払うとき、話を聞くと3要素が揃っているので苦笑いする。順序が逆なのだ。これは鼻が利くというやつなのだろう。
鼻が利く感覚の正体
"鼻が利く"に関してはいまだによくわからない。ストックピッキングや手術と同じで天賦の才かもしれない。
育ちも生まれも経験も全く異なる私と奥さんが同じように鼻が利くのはなぜか。1つ仮説があるが、ここでは控える。
まあ鼻が利くから俺と結婚してくれたのかな、なんつって。
騙しの先に本物がある
騙しのテクニックの先に本物がポンと置いてあったりする。
何でもやってみるのがいい。お金も経験もケチった先にあるのは1つだけだ。
ゆっくり貧乏になる。
さて、今回のタイトルを思い出そう。
稼げるレアリティーとはなにか？
レアリティーだけでは稼げないことに気づいたかも知れません。逆に言えば稼げるレアリティーは「作れる」こともわかったはずです。
僕は鼻が利く人にしか辿り着けない商品を用意しています。そのためストーリーや人間関係やコミュニティーからできるだけ距離をおいています。マーケティングを一切しないのも僕の特徴ですね。理由は単純で商売で金を稼ぐ必要が無いからです。
これは僕の話を語っているわけではありません。世の中にはそういった人もいるということを知っておくと便利です。お金を稼ぐ必要が無ければストーリーを共有する必要がありません。つまりプロダクトアウトの本物というのが世の中に沢山あるのです。
この記事では何でもないものを本物にする方法と、世に出ていない本物があることの両方を解説しました。
これをどう扱うかは人それぞれでしょう。なぜ二つ同時に話したか、そこに第三のレイヤーがあります。ぜひ僕が本当は何を伝えたいのか考えてみてください。
