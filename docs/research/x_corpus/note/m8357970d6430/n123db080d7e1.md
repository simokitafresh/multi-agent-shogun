# 金の卵を産むニワトリになろうとした勤務医

<!-- key=n123db080d7e1 publish_at=2024-11-11T14:15:21.000+09:00 price=100 full=True like=14 -->

少し前に大学の研修同期の飲み会があった。久しぶりにあった仲間はいつの間にか少しだらしない体型になっていたようだが、楽しい時間を過ごしていた。
いつもは別に高尚な医学の話はあまりなく、子どもの学費や、奥さんの浪費癖、生活ぶりといった自慢とも愚痴とも言える話で盛り上がるものだが、その日は途中から重い雰囲気に変わりつつあった。
大学に残って関連病院の部長になった彼が肩を落として話していた内容が皆の耳に痛いほど響く。
不動産投資を始めてさ、将来のためと思って地方に物件を買ったんだけど…紹介された医師に騙されたみたいで不良物件だったんだ。

彼はいつも前向きで、患者にも同僚にも気配りを欠かさない。そんな彼が抱える挫折の言葉を聞くのは初めてだった。
二人目が中学受験を控えてててさ、ほら、うちは小学校受験希望に行けなかったし、だから奥さんに熱が入ってさ塾の学費に夏期講習、最近は医局外のバイトも行けなくなくなったしね。ヤバいと思って焦ってた……

コロナ以降の働き方改革は知っていたが、開業医の自分には遠くに感じていた。しかし身近な友人から聞くとまた実感が変わる。
