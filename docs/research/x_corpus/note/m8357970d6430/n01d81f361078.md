# Windows 11でClaude Code Actionを導入してMaxプランで利用する手順

<!-- key=n01d81f361078 publish_at=2025-06-01T22:24:54.000+09:00 price=0 full=True like=1 -->

Windows 11でClaude Code Actionを使用できるようにするための方法をまとめました。自分でやってみると色々とトラップがあったので初めての人向けに改良しました。
これによりGitHubのIssueやPRで@claudeとメンションすると、ClaudeがコードレビューやコードGenerationを実行します。Maxプラン（月額$100）の範囲内で追加料金なしで利用することができます。

🪟WindowsとUbuntu🐧（WSL2）の切り替え方法
🐧Ubuntu（WSL2）を起動する
方法1：スタートメニューから
Windowsキーを押す

「Ubuntu」と入力

「Ubuntu 24.04」をクリック

方法2：Windows Terminalから
Windows Terminalを開く

新しいタブの「∨」をクリック

「Ubuntu」を選択

方法3：PowerShellから
wsl
🐧Ubuntu（WSL2）を終了して🪟Windowsに戻る
方法1：ウィンドウを閉じる
Ubuntuウィンドウの「×」ボタンをクリック

方法2：exitコマンド
exit
方法3：完全にWSL2を停止する
🪟Windows PowerShellで実行：
wsl --shutdown
現在どちらにいるか確認する方法
見た目で判断：
🪟Windows PowerShell： 青い背景、PS C:\Users\名前>

🐧Ubuntu（WSL2）： 黒い背景、ユーザー名@PC名:~$

コマンドで確認：
# これが動けば🐧Ubuntu
pwd
# /home/username と表示される

# これが動けば🪟Windows PowerShell
Get-Location
# C:\Users\名前 と表示される
前提条件
あなたに必要なもの：
Windows 11の管理者権限

Claude Maxプランのアカウント

GitHubアカウント

VS Code（インストール済み）

2-3時間の作業時間

導入手順
1. WSL2をインストールする
🪟Windows PowerShell（管理者権限）で実行：
PowerShellを管理者権限で開きます。以下のコマンドを実行します：
wsl --install ubuntu-24.04
PCを再起動します。🐧Ubuntuが自動起動します。ユーザー名とパスワードを設定します。
2. 必要なツールをインストールする
🐧Ubuntu（WSL2）で実行：
Ubuntuターミナルで以下を順番に実行します：
# システムを更新
# 注：aptコマンドはシステム管理なのでsudoが必要です（安全）
sudo apt update
sudo apt upgrade -y

# NVMをインストール（sudoは不要）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
. "$HOME/.nvm/nvm.sh"

# Node.jsをインストール（sudoは不要）
nvm install 22

# GitHub CLIをインストール
# 注：システムツールなのでsudoが必要です（安全）
curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo dd of=/usr/share/keyrings/githubcli-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null
sudo apt update
sudo apt install gh -y
3. GitHub CLIで認証する
🐧Ubuntu（WSL2）で実行：
gh auth login
すべての質問で最初の選択肢を選びます。ブラウザで認証を完了します。
4. Claude Codeをインストールする
🐧Ubuntu（WSL2）で実行：
npm install -g @anthropic-ai/claude-code
エラーが出た場合は、npmグローバルディレクトリを変更します：
🐧Ubuntu（WSL2）で実行：
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
npm install -g @anthropic-ai/claude-code
5. プロジェクトディレクトリを準備する
重要： WSL2から🪟Windowsファイル（/mnt/c/）へのアクセスは10-100倍遅いため、プロジェクトはWSL2側に配置します。
🐧Ubuntu（WSL2）で実行：
# WSL2側にプロジェクト用ディレクトリを作成
mkdir -p ~/projects
cd ~/projects

# 既存のリポジトリをクローンする場合
git clone https://github.com/[あなたのユーザー名]/[リポジトリ名].git
cd [リポジトリ名]

# または新規プロジェクトを作成する場合
mkdir [プロジェクト名]
cd [プロジェクト名]
git init
🪟Windowsからアクセスする方法：
エクスプローラーのアドレスバーに入力：\\wsl$\Ubuntu\home\[Ubuntuユーザー名]\projects

6. Claude Codeにログインする
🐧Ubuntu（WSL2）で実行：
プロジェクトディレクトリ内で：
claude
ブラウザが開きます。Maxプランアカウントでログインします。
Claude Code内で実行：
/status
ログイン確認後、Ctrl+Cで終了します。
7. OAuthトークンを取得する
🐧Ubuntu（WSL2）で実行：
cat ~/.claude/.credentials.json
3つの値をメモします：
access_token

refresh_token

expires_at

8. GitHubにSecretsを設定する
🪟Windowsのブラウザで操作：
GitHubのリポジトリページで：
Settings → Secrets and variables → Actions

以下の3つのSecretを追加：
CLAUDE_ACCESS_TOKEN

CLAUDE_REFRESH_TOKEN

CLAUDE_EXPIRES_AT

9. GitHub Actionワークフローを作成する
🐧Ubuntu（WSL2）で実行：
プロジェクトディレクトリで：
mkdir -p .github/workflows
code .github/workflows/claude.yml
VS Codeで編集：
以下の内容を保存します：
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
  issues:
    types: [opened, assigned]
  pull_request_review:
    types: [submitted]

jobs:
  claude:
    if: |
      (github.event_name == 'issue_comment' && contains(github.event.comment.body, '@claude')) ||
      (github.event_name == 'pull_request_review_comment' && contains(github.event.comment.body, '@claude')) ||
      (github.event_name == 'pull_request_review' && contains(github.event.review.body, '@claude')) ||
      (github.event_name == 'issues' && (contains(github.event.issue.body, '@claude') || contains(github.event.issue.title, '@claude')))
    
    runs-on: ubuntu-latest
    
    permissions:
      contents: write
      pull-requests: write
      issues: write
      id-token: write
    
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 1
      
      - name: Run Claude Code
        uses: grll/claude-code-base-action@main
        with:
          use_oauth: 'true'
          claude_access_token: ${{ secrets.CLAUDE_ACCESS_TOKEN }}
          claude_refresh_token: ${{ secrets.CLAUDE_REFRESH_TOKEN }}
          claude_expires_at: ${{ secrets.CLAUDE_EXPIRES_AT }}
          timeout_minutes: "30"
10. GitHubにプッシュする
🐧Ubuntu（WSL2）で実行：
git add .github/workflows/claude.yml
git commit -m "Add Claude Code Action workflow"
git push origin main
使い方
🪟Windowsのブラウザで操作：
GitHubでIssueを作成し、本文に@claude こんにちはと書きます。数分待つと、Claudeが返信します。
VS Codeでの開発
🐧Ubuntu（WSL2）で実行：
WSL2側のプロジェクトを直接編集（高速）：
cd ~/projects/[プロジェクト名]
code .
VS CodeがWSL2拡張機能を使って開きます。ファイル保存やGit操作が高速に動作します。
