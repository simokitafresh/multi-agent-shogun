# 誰に弾を渡すか。責任と報酬は同じスケールで測れ

<!-- key=n504497026dd8 publish_at=2025-04-30T13:47:39.000+09:00 price=0 full=True like=7 -->

ヤーマン、今日も生きてるか？俺はバムだ。今日はな、医者の世界の話をしようと思う。数字と誇りと責任が交差する、ちょっと冷たい話だ。
病院でもクリニックでも、経営の中で一番重くて、一番デカいコストは人件費だ。特に医師。高い報酬、でも唯一の“売上を直接生み出す存在”だ。ここがポイントだぜ。
つまり、医師の売上ってのは、単なる数字じゃねぇ。それは「責任量」だ。どれだけの患者を抱え、どれだけの行為を積み重ねたか──組織に対して、どれだけの貢献をしたかの可視化なんだよ。
でもよ、問題は診療科の間じゃねぇ。同じ診療科の中で、医者同士の売上がバラッバラってとこにある。耳鼻科の医者が整形のやつより売上低いのは当たり前。でも同じ耳鼻科にいて、診療報酬も時間も共有してて、売上が全然違うってのは、これはもう“構造的な負債”だ。
低い医者も高い医者も、同じだけ固定費を食ってる。それどころか、看護師もコメディカルも一緒に使ってる。で、売上が低い医者がのさばるってことは、高い医者の稼ぎが横から吸われてるってことだ。これを放っとくと、ちゃんと獲物を狩ってるハンターほど消耗して、やがてこの荒野から抜けていく。
ある経営者は「教育のため」「バッファーとして」って言い訳をする。でもそれ、本当に組織で合意された配置か？本当に必要か？それを見極めるのが、経営ってやつの本質だ。
売上の低い医者が居続ける。でも報酬は同じ。それが続けば、組織のモチベーションも、利益率も、最終的には医療の質も全部下がる。これはただの“個人の問題”じゃねぇ。構造の話だ。放っとくと組織ごと腐る。
じゃあどうするか。インセンティブを作るんだ。でも短期の数字に踊らされるな。1ヶ月の“頑張り”なんて、すぐにインチキに変わる。だから、12ヶ月とか24ヶ月の長期平均で見る。安定して、ちゃんと患者に向き合い続けたヤツに報いる仕組み。一発じゃなく、継続的な覚悟が報われるようにするんだ。
昇給は指数関数的に、降給は緩やかに。この信賞必罰の設計が、組織を動かす。優秀なヤツは残り、働かないヤツは自然と抜けていく。それが健全ってもんだ。
ただな、ここで絶対に間違えちゃいけねぇのは、「楽に雇えて、そこそこ使える医者」ばっかを並べて、“標準化”って名の下に、属人性を潰すこと。それは組織の効率化でも合理化でもねぇ。それは、穏やかな自殺だ。
国も行政も、こっちに誘導してる。個性を潰し、医者をモノにして、コストを削って“効率”と“再現性”だけを残す。でもな、それで生まれるのは、魂の抜けた医療だ。責任も誇りもなくなる。患者が一番損をする。
だからこそ、俺たちは騙されちゃいけねぇ。質の低い医者を、明示的にじゃなくて静かに淘汰していく構造をつくる。能力が証明できなきゃ、報酬は自然に下がる。そこに怒りも、恨みも、いらねぇ。ただの構造、ただの設計の話だ。
短期的に売上が下がっても、人が足りなくても、原則は崩すな。能力に応じて支払う。質の低い医者は安く雇う。それだけのことだ。
医療を続けるってのは、向き合い続けたヤツが報われ、向き合わなかったヤツが去っていく構造をつくることだ。それが経営の責任であり、医者としての尊厳を守るための条件なんだよ。
