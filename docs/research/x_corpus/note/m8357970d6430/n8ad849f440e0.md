# 診療報酬1点8円。財務省「持続可能な社会保障制度の構築（財政各論Ⅱ）」からクリニック経営に直結する6ポイントまとめ

「1点8円」に。衝撃的な憶測がネットを駆け巡りました。シンプルな試算では全診療科で赤字化すると思われます。
今回は速報をかね、2025年4月23日に財務省が公表した資料「持続可能な社会保障制度の構築（財政各論Ⅱ）」を中心とした公式資料（PDF全129ページ）を基に、診療報酬制度改定および地域単価差導入がクリニックの収益構造に及ぼす影響を整理し、利益率シミュレーションを通じて経営上のポイントをまとめてみます。

【資料の大項目構成】
総論：社会保障関係費の伸びと財政健全化目標

医療：診療報酬・薬価・医療提供体制・医療DX

介護：給付と負担、介護人材・テクノロジー活用

障害福祉：地域生活移行と就労支援

生活保護等：最低生活基準・医療扶助の適正化

129ページのPDFから、今回は6つに絞ってまとめます。
