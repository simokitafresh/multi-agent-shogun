# 社会保険料率をハックしないで減らす

<!-- key=n73baad728f42 publish_at=2024-11-03T22:42:23.000+09:00 price=500 full=True like=14 -->

社会保険料の仕組みはここでは語りません。
これは会社負担分込みでざっくり3割の社会保険料率を減らすハナシ

健康保険・厚生年金の保険料額表
社会保険料は健康保険と厚生年金の2つに分かれます。給与額に応じて健康保険は50段階、厚生年金は32段階のテーブルが設定されています。
また40才を越えると健康保険には介護保険料が加算されます。
社会保険料の料率（種別）
　健康保険（40才未満）9.98%
　健康保険（40才以上）11.58%
　厚生年金　18.3%
社会保険料の合計料率（年齢別）
　40才未満（28.28%）
　40才以上（29.88%）
給料の3割は社会保険料で吹き飛びます。
実は社会保険料率はセコいハックなどせずに減らすことが出来ます。
