# 「早い思考力」の鍛え方：情報量と知識構築の実践的アプローチ、obsidianの前に読むべき基本

<!-- key=na5775dec4bb7 publish_at=2025-05-12T14:41:51.000+09:00 price=0 full=True like=11 -->

早い思考力とは何か？
早い思考力とは、数秒以内で適切な結論を導き出せる思考処理能力のことです。一般的な例で言えば、トイレで用を足した後に「お尻を拭くべきか」を5分も10分も考えることなく、即座に結論を出せるような思考スピードです。実践的な「早い思考」はバム流に言えば「数秒で結論を出す能力」であり、ビジネスや日常生活での意思決定プロセスを大幅に効率化します。
早い思考力の本質はヒューリスティックスにある
私は「早い思考力」を専門用語で「ヒューリスティックス（経験則）」と呼ぶことが多いです。早い思考力＝ヒューリスティックスは、脳内に蓄積された経験則や知識パターンを瞬時に参照することで成立します。この能力は生まれつきのものではなく、適切な方法で鍛えることが可能です。
情報量が思考速度を決定する
早い思考力を鍛える最も重要な要素は「情報量」です。十分な情報量がなければ、思考は浅いレベルにとどまり、真に価値ある結論を導き出すことができません。情報量を増やす方法には以下の2つのアプローチがあります。
ヒューリスティクスと情報の量についてのメモ1. 外部からの情報取得
最も直接的な方法は、多様な情報源から知識を取り入れることです。例えば：
書籍を読む（私の場合は月に10冊以上）

オーディオブックを聴く

専門性の高いYouTube動画を視聴する

Twitterなどのソーシャルメディアから厳選した情報を収集する

情報の取得方法は個人の学習スタイルに合わせるべきです。私自身は幼少期から文字を読むことに慣れているため書籍を好みますが、これはあくまで個人的な嗜好であり、重要なのは継続的に質の高い情報を大量に取り入れることです。
2. 自己構築による情報拡張
外部からの情報取得だけでなく、自分自身で情報を構造化し拡張することも重要です。これには以下のような具体的方法があります：
メモ取りの習慣化
読書やコンテンツ消費時に、自分の言葉で感じたことや学んだことを書き出します。この作業自体が情報の定着と拡張を促進します。
効果的なメモ管理システム
私が実践している具体的なメモ管理方法：
タイトルに番号を付ける（体系的な管理のため）

追加情報が必要な場合は1.1のように小数点番号を振る（ウィトゲンシュタインの手法を参考）

関連するメモ同士をリンクで接続する

定期的に過去のメモを見直し、新たな気づきがあれば新規メモを作成する

直近数日間のメモを1日に数回読み返す

思考の変遷がわかるよう修正ではなく新規メモとして追加する

自分だけの知識体系を作る価値
自分でメモを取り、知識を整理し、独自の体系を作り上げる過程そのものに大きな価値があります。他人から与えられた知識をそのまま受け入れるだけでなく、自分の言葉で噛み砕き、再構築することで、その知識は真に「自分のもの」となります。
このプロセスは一見面倒に思えるかもしれませんが、習慣化することで負担は大きく軽減されます。完璧を求める必要はなく、読んだ本すべてをメモする必要もありません。私自身、10冊に1冊程度しかメモしていません。重要なのは継続性と自分に合ったシステムを構築することです。
早い思考力がもたらす競争優位性
早い思考力を鍛えることは、競争環境において大きなアドバンテージとなります。ゆっくり考える場合、最終的には純粋な能力差が結果を左右します。しかし、早い判断が求められる状況では、強者でもミスを犯す可能性が生まれます。その瞬間こそ、弱者が逆転できる唯一のチャンスなのです。
将棋やビジネス交渉など、様々な場面でこの原則は適用されます。思考のスピードを高めることで、より多くの機会を掴むことが可能になるのです。
実践的なアウトプット習慣
インプットと同様に、アウトプットも重要です。特に他者の言葉をそのまま引用するのではなく、自分の言葉で表現することが思考力向上には効果的です。例えば：
非公開のブログで関心あるトピックについてリンク集を作る

気になる情報に自分のコメントや考察を追加する

定期的に自分の考えをまとめ、文章化する

これらの習慣を半年以上続けると、自然と思考の速度と質が向上していることに気づくでしょう。私自身は以前はEvernoteを使用していましたが、現在はブログの下書き、GoogleKeep、Obsidianなどの複数のツールを状況に応じて使い分けています。
まとめ：早い思考力は継続的な実践で必ず向上する
早い思考力は一部の恵まれた人だけが持つ才能ではなく、適切な方法で継続的に鍛えることができるスキルです。情報量の拡大と自己構築の習慣化という二つの柱に焦点を当て、自分に合ったシステムを構築していけば、誰でも思考速度と質を高めることが可能です。重要なのは「量」と「継続性」、そして自分で知識体系を構築する喜びを感じることです。
