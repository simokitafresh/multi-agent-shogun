# 開業医として「清くまっとうに富む」ために欠かせぬ経営者としての3つの視点

開業前～開業直後の先生方は不安だと思います。僕も最初はこれでいいのかと不安でした。ネット上にはスーパーマンのような行動力で圧倒的成功を瞬時に遂げる先生もいます。しかし以前アンケートをとったところ売上1億をこえるクリニックはネットのイメージよりも少ないのではと思っています。

このセリフは、開業（特に開業後間もない段階など）の経営方針について述べたものです。その他のビジネスにも応用できると思います。ポイントは下記の3点に要約できます。ツイートの意味について解説しながらまとめていきます。

第一のポスト「開業医が意識するべき三つの視点」
1. 「大きくしたいなら売上」について
主眼: 事業を拡大したい場合は売上高を追うことが重要である、という考え方。

理由: 新規顧客の獲得や市場シェアの拡大など、「規模」を伸ばすための指標として売上高が分かりやすいため。

リスク: 売上を伸ばすことに集中しすぎると、粗利や利益を意識しづらくなりがち。規模拡大の過程でコスト（人件費や広告費など）が増え、赤字になりやすい。

2. 「安定させたいなら利益率」について
主眼: 安定を求めるなら売上よりも「どれだけ効率良く利益を得られているか」を重視すべき、という考え方。

理由: 利益率（売上に対しての利益の割合）が高いということは、投資やコスト構造などが堅実であり、経営が安定しやすい。

リスク: 利益率ばかり追いかけると、投資や設備拡充をためらいがちになる。短期的には安定する反面、長期の成長機会を逃すことがある。

3. 「バランスさせるのが一人あたりの利益額」について
意味: 「全体の売上」と「利益率」という二つの側面を“ほどよく”両立するために、分母を「人数」にして考えるという発想。
ここでの「一人あたり」とは、社員やスタッフ、または顧客数（医療機関なら患者数）など、状況に応じて「数」を使い分ける。

「売上を上げたい」→来院数や客数を増やす

「利益率を上げたい」→サービス内容・質を向上させ、単価やリピート率を上げる

メリット: 一人あたり（スタッフあたり/顧客あたり）の収益を把握することで、過剰なコストをかけずに効率的に売上も利益も確保できているかを測定しやすい。

リスク: 一人あたりを重視しすぎると、コストカットや単価アップばかりを考えてしまう可能性があるので、バランス感覚が必要。

4. 第一のポストまとめ
土台作りの段階: 開業当初はまず売上を増やし、スタッフやシステムを軌道に乗せる必要がある。一方、無理な設備投資や過剰な人員拡充を行うと、経費が膨らみ、利益率が下がって経営が不安定になる。

人あたりの採算管理: 医療機関であれば、1名の医師・看護師・スタッフがどのくらいの患者数を対応できるか、その際の利益はどれくらいになるのか、という基準を把握しておくと、売上拡大と安定した利益のバランスを取りやすい。

売上高は利益の源泉となるため初期には最重要課題となる。クリニックの売上は患者数×診療単価＝レセプト枚数×レセプト平均点数。保険診療では診療単価には限界があるため集患がキーポイント。集患のキモは差別化。まずは競合より＋アルファの”定量的”な優位性を作るとよい。

第二のポスト「大きくしたいなら売り上げ」
第二のポストは開業したばかりのクリニックが「売上を上げるためには何がポイントになるか」を端的にまとめたものです。ポイントは大きく分けて4つあります。
1. 初期段階での売上高の重要性
「売上高は利益の源泉となるため初期には最重要課題となる」

意味: クリニックを軌道に乗せるには、まず「売上」を安定して上げることが最優先になる、ということ。

背景: 開業後は家賃や人件費、設備投資などの固定費を維持しながら安定した利益を確保する必要がある。そのためには、そもそもの売上高が不足していると経営が成り立たない。

補足: 「売上＝患者数×診療単価」は非常にシンプルだが、保険診療では診療単価（単価＝レセプト平均点数）に上限があるため、集患（患者数を増やす）が売上増の主たる手段となる。

2. クリニックの売上構造
「クリニックの売上は患者数×診療単価＝レセプト枚数×レセプト平均点数」

意味: 医療機関の売上は、基本的に「何人の患者が来院し、その患者一人あたりどれくらいの診療報酬が得られるか」で決まる。

ポイント:
「患者数」＝ 診療を受けに来る人数（レセプト枚数）

「診療単価」＝ 患者一人あたりの診療報酬（レセプト平均点数×1点あたりの点数単価）

保険診療の制約: 日本の医療保険制度では、基本的に報酬点数が国で決められているため、「診療単価」を劇的に上げることは難しい。自由診療とは違い、価格を自由に設定できない。

3. 集患がカギとなる理由
「保険診療では診療単価には限界があるため集患がキーポイント」

意味: 売上＝患者数×単価 だが、単価を上げにくいので「患者数（集患）」を増やすことが売上増のための現実的な戦略となる。

具体策: 地域での認知度アップ（ネット検索・口コミ対策・看板・チラシなど）、利便性（アクセスや待ち時間の短縮、オンライン予約など）の改善、顧客満足度を上げる仕組み（丁寧な診察、スタッフ対応、院内環境）など、総合的な施策が必要。

4. 差別化と“定量的”な優位性
「集患のキモは差別化。まずは競合より＋アルファの”定量的”な優位性を作るとよい」

意味: 近隣に同種のクリニックが多数ある場合、患者が「ここに行きたい」と思う決め手が必要になる。単なる「雰囲気がいい」だけではなく、「○○検査が充実している」「○○疾患の専門外来がある」といった数字や実績で示せる強みを作ることが大切。

なぜ“定量的”なのか:
患者数・診療実績・専門資格の人数など、数字で示せるメリットは患者にとって説得力が高い。

「最新機器を導入している」「検査結果が通常より早く出る」「平均待ち時間が○分」など、具体的でわかりやすい優位性が集患に大きく貢献する。

5. 第二のポストまとめ
売上高は、クリニック経営の土台となるため開業初期にはとくに重要。

売上構造は「患者数×診療単価」だが、保険診療では単価アップに制限がある。

集患（患者数増加）こそが保険診療の売上増の要。

差別化を図るには、定量的・実績ベースのわかりやすい優位性をつくる。

つまり、開業当初のクリニックにとっては「まず売上を安定して得られるように、周囲の競合院との差別化を図り、患者さんが選びやすい“数値で示せる強み”をつくること」が最重要です。
利益率が低いと予期せぬ出来事に耐えられない。しかし初期投資を渋りすぎると限界までの天井は低くなってしまう。ケチになるのではなく費用対効果を意識する必要がある。検査・処置・診療行為、それぞれの利益率を把握しよう。利益を生みだすものに対してシビアな視点を持つ事が近道となる。

第三のポスト「安定させたいなら利益率」
第三のポストでは、主にクリニックや医療機関における「初期投資」と「利益率」、そして経営のバランス感覚について言及しています。ポイントを順番に解説します。
1. 利益率が低いと予期せぬ出来事に耐えられない
意味: 利益率（利益 ÷ 売上）が低い状態だと、想定外の出費や経済環境の変化、新規競合の出現など、突発的なリスクに対応する資金的余力が少なくなってしまう。

具体例:
医療機器の故障や買い替え、想定外のスタッフ退職に伴う採用コスト。

新型感染症の拡大など予測不能な事態への防疫投資や設備投資。

結果: 資金がないまま、さらに借入れやリスケジュールなどに追い込まれるリスクが高まる。

2. 初期投資を渋りすぎると限界までの天井は低くなる
意味: 開業やリニューアルなどの初期段階で、必要な投資（施設整備、医療機器導入、人材確保など）を極端に抑えすぎると、将来的に売上やサービスの質を高められる上限が低くなり、伸びしろを失う可能性が高まる。

具体例:
最先端の医療機器を導入せずに競合と差別化できない。

スタッフを最低限しか雇わないため、診療効率が上がらず患者数を増やせない。

結果: 成長機会を失い、結果的に利益率の確保にも悪影響を及ぼす。

3. “ケチ”ではなく「費用対効果」を意識する
意味: 投資額をやみくもに減らすのではなく、「投資に見合う効果（リターン）が得られるか」を重視する必要がある。

費用対効果（ROI）とは:
ROI(Return on Investment) = 投資によって得られるリターン（利益やサービス向上） / 投資額

「コストをかける価値がある設備か？」「導入後どのくらい患者満足度や売上増が見込めるか？」など、定量的・客観的に判断する。

例: 「最新の内視鏡導入で検査件数や診療単価が増える可能性が高いなら、多少高額でも投資を検討する意義がある」といった考え方。

4. 検査・処置・診療行為のそれぞれの利益率を把握する
意味: 医療機関における検査・処置・診療行為は、それぞれ保険点数やコスト構造が異なるため、一律に利益率が同じとは限らない。どの行為がどれだけ利益を生み出すかを把握しておくことが重要。

具体的に何をするか:
レセプト点数 × コスト（薬剤・材料費、スタッフ人件費、検査キット費用など）を計算し、その検査や処置の実質的な利益率を試算する。

見込み利益率が低い項目が多い場合は、運用体制や費用を見直す。

高利益率の検査や治療であっても、需要（患者ニーズ）がなければ大きな利益は望めないので、市場や患者層のニーズとのバランスが重要。

結果: 「どの診療行為を強化すれば効率的に利益を伸ばせるか」が明確になる。

5. 利益を生みだすものにシビアな視点を持つ事が近道
意味: 「利益」は悪いことではなく、事業や診療所を継続・発展させるために必要なもの。

具体例:
「患者さんが必要としている検査や治療で、かつある程度利益が出るもの」を積極的に取り入れる。

投資額（設備、スタッフ教育など）を回収できるか、常にシビアに検証する。

ゴール: しっかりと利益を確保しながら患者ニーズに応え、かつ新たな投資も回していける好循環を生み出す。

6. 第三のポストまとめ
利益率が低いままだと突発的なリスクへの耐性が弱く、経営の継続が危うくなる。

初期投資を必要以上に抑えると将来の成長・差別化が難しくなる。

単に「ケチになる」のではなく、投資対効果をよく考え、適切に資金を投下する。

検査・処置・診療行為ごとの利益率を把握し、どこに力を入れるべきか見極める。

利益を重視する姿勢を持つことが、結果的に患者サービス向上や安定経営につながる。

このように、クリニックなどの医療経営では、売上だけでなく利益率の管理や投資の優先順位を定めることが、安定した経営基盤を作り出すカギとなります。

最後となる第四のポストでは、一人あたりの利益額にとらわれすぎることのリスクを指摘すると同時に、クリニック経営において「売上高」と「利益率」をまず優先すべきという考え方を示しています。ポイントを順に解説します。
1. 一人あたりの利益額は“バランス”を測る通信簿
「一人あたりの利益額はバランスがとれているかの通信簿。」

意味
事業における人数（医師、スタッフ数など）に対して、どのくらいの利益を生み出せているかを示す指標。

バランスの指標としては有効だが、それ自体を最優先に追求すると偏りが生じる可能性がある。

背景
「売上（規模）」と「利益率（経営の効率・安定性）」の両軸をある程度満たしているかを測るうえでの指針。

一見して高い数字が出ていれば「効率的」な気がするが、裏を返せば「人件費を抑えすぎている」「拡大余地がない」などの問題が潜んでいる場合がある。

2. 売上高＆利益率 ＞ 一人あたりの利益額
「あくまで優先度は売上高＆利益率 ＞ 一人あたりの利益額。」

意味
経営上最も大切なのは「全体の売上を大きくしていくこと」と「適正な利益率を確保すること」。

この2つがあってはじめて事業が安定し、成長のための投資が可能になる。

「一人あたりの利益額」はあくまで後から確認する指標という位置づけ。

なぜ優先度が高いのか
売上高がなければ固定費や設備投資をカバーできないため、事業存続が難しくなる。

利益率が低いと、設備のメンテナンスや非常時への備えなどに支障が出るため、経営体力が弱くなる。

一人あたりの利益は売上高や利益率の土台がしっかりある状態でこそ、はじめて意味を持つ。

3.一人あたりの利益額を突き詰めるリスク
「高単価路線やワンマンクリニックに行きがちだが要注意。」

具体例
高単価の自由診療や専門外来のみを追求して、少人数で運営する。

一見すると効率が良く、利益率も高く見えるが、集患（患者数拡大）や将来的な事業拡張が難しくなりがち。

リスク
経営の伸びしろを失う: 人を増やさない、設備投資を控えるなどの経営手法だと、売上の上限が早く見えてしまう。

集患力の低下: 高単価路線に寄り過ぎると、患者層が限定され、結果として総患者数を増やせない。

スタッフ育成やチーム医療の機会損失: “ワンマン”状態だと、医師やスタッフが十分に育たないため、将来の多様な医療ニーズに対応しにくくなる。

4. 効率追求のつもりが、収入アップの可能性を狭めていないか
「効率を求めたつもりが結果的に収入の伸びしろを失っていないかを考える必要がある。」

意味
“費用を減らして一人あたりの利益を高める” だけに注力していると、事業規模の拡大や新たな収益源の開拓を妨げる可能性がある。

トータルの収益向上を考えるなら、設備投資や人材への投資は時に必要不可欠。

具体策
定期的に客観的なデータで確認: 「一人あたり利益＝高い」状態でも、売上成長率や利益率はどうなっているのかを総合的に比較する。

投資計画の策定: たとえば「2年後に新しい診療科を立ち上げるためにスタッフを増やす」「新しい検査機器を導入し、サービスの幅を広げる」など、中長期的な視点を持つ。

スタッフ・患者との信頼関係づくり: “一人で稼ぐ”モデルだと、院長自身の稼働が限界になった時点で伸びが止まる。スタッフを育てて診療の質を上げることで、患者満足度とリピート率を高める余地が生まれる。

5. 第四のポストまとめ
一人あたりの利益額は「どれだけバランス良く運営できているか」を見る上での“指標”だが、最優先にはしない。

経営を支える土台となるのは、あくまで売上の拡大と適正な利益率の確保である。

一人あたりを突き詰めると「高単価＆少人数」という運営形態になりがちだが、これは将来的な成長や安定運営の妨げになる恐れがある。

効率を追い求めることは大切だが、「長期的な売上増」「利益率改善」「スタッフ育成」に対する投資も同時に検討し、伸びしろを確保することが重要。

結局のところ、「一人あたりの利益額」よりもまずは「売上高」と「利益率」をしっかりと成長させ、そのうえでバランス指標として一人あたりの利益額を活用するのが健全なクリニック経営の在り方だといえます。
より良い医療を提供するために
