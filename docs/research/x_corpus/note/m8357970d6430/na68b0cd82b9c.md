# スモールビジネスや副業でサヴァイブしたいなら真水のキャッシュを直視しろ

<!-- key=na68b0cd82b9c publish_at=2026-07-23T13:22:41.000+09:00 price=0 full=True like=11 -->

ヤーマン、今日も生きてるか？俺はバムだ。今日は商売やってるヤツには避けて通れねぇ話をするぜ。裏のフリーザーに冷えたコークがある。俺の分もラムコークを作ってくれ。
それじゃあ始めるか。そこに座って聞いてけ。
今日はお前に足らない真水のキャッシュのハナシをしよう。
売上が伸びた？粗利が高い？...だからどうした
街のイーンフルエンサーどもは「売上前年比アップ！」「粗利率90％超え！」なんて数字を振りかざして、まるで安全な避難所を見つけたみてぇにはしゃいでやがる。
悪くねぇ数字だよ。否定はしねぇ。
だがな、それだけ見て「ウチは儲かってる」なんて思ってるなら、お前はゾンビの群れのど真ん中で昼寝してるのと同じだぜ。
商売で本当に見るべき数字はたった一つ。税金を払い、借金を返し、設備を直した後に、いくらの現金が手元に残ったか。これだけだ。この「真水のキャッシュ」を見ねぇ経営者は、弾の残数を確認しないで荒野を歩いてるようなもんだ。いつ詰むか分からねぇ。
粗利はデカくても安心すんな
粗利ってのは売上から原価を引いただけの数字だ。家賃も人件費も光熱費も広告費も、まだ何も引いてねぇ。
粗利率90％？結構なこった。だがそっから人を雇い、場所を借り、電気をつけ、宣伝を打ち、設備の償却を食らう。ようやく残るのが営業利益だ。
粗利ってのはな、荒野の旅で言やぁスタート前のお天気みてぇなもんだ。晴れてたからってドアの影にゾンビがいねぇとは限らねぇだろ？途中経過の数字で安心するな。ゴールまで歩ききった後に何が残ってるか。そこだけ見ろ。
黒字なのに金がねぇ？そのカラクリを教えてやる
「税引後利益がちゃんと出てるのに、なぜか金がねぇ」...この現象に心当たりがあるヤツ、少なくねぇだろ？
タネを明かしてやる。犯人は借入金の元本返済だ。
金融機関に払う利息は経費になる。だが元本の返済は経費にならねぇ。帳簿上は「負債が減った」ってだけの取引だからだ。
税引後利益が2,000万出てても、年間1,500万の元本返済があったらどうなる？手元に残るのは500万だ。帳簿の上じゃ黒字でも、財布の中身はスッカラカン。これが「黒字倒産」の正体だぜ。利益って数字に騙されて、実際の現金を見てねぇヤツがハマる罠だ。街のイーンフルエンサーは「黒字だから大丈夫！」なんて無責任なことを言いやがるが、現金が尽きたら商売は終わりだ。ゾンビに囲まれた時、銃はあっても弾がねぇ...そんな状態で生き残れるわけがねぇだろ。
...おっと、氷のおかわりが必要だな。今日は暑いからもう一杯飲め。
設備投資は利益じゃなく現金を直接食う
商売を続けるには設備がいる。機械の更新、内装の修繕、車両の買い替え、システムの入れ替え。事業ってのは維持するだけでも、キャッシュが出ていくんだ。
ここにもう一つ罠がある。設備を買っても、会計上はその年に全額が経費にならねぇ。耐用年数に応じて減価償却費として何年もかけて費用計上される。だがキャッシュは買った瞬間に出ていく。
損益計算書じゃ利益が残ってるように見えても、デカい設備投資をした年は銀行口座がガッツリ削られてる。帳簿と口座残高が全然違う、なんてのはザラにある話だ。
帳簿上の利益はな、荒野で言やぁいつのものかも分からねえ地図に書いてあるオアシスみてぇなもんだ。実際に行ってみたら干上がってたなんてことがよくあるんだ。
真水のキャッシュ、これが生存の指標だ
じゃあ何を見りゃいいのか。
税引後利益に減価償却費を足す。減価償却費ってのは帳簿上の費用であって、実際に現金が出ていくわけじゃねぇから、まずそれを戻してやる。そっから借入金の元本返済を引き、設備投資を引き、運転資金が増えた分も引く。最後に残ったもの、それが真水のキャッシュだ。
厳密な金融用語のフリーキャッシュフローとは定義がズレるところもあるが、スモールビジネス回すうえじゃ、この数字を把握してるかどうかで生死が分かれる。
これが商売における残弾数だ。常に把握しとけ。
残ったキャッシュから逆算しろ
人を増やす。新しい店を出す。高額な設備を入れる。自分の報酬を上げる。全部やりてぇだろ。分かるぜ。最初は夢がある方がいい。
だがな、その判断を売上や粗利だけで下すのはゾンビの群れに突っ込むのと同じだ。
見るべきは、税金と返済と必要な投資を終えた後に毎年どれだけのキャッシュが残るか。その金額がお前の行動可能範囲を決める。
税引後利益がデカくても、返済後のキャッシュが細けりゃ無理な拡大はできねぇ。背伸びして死んだヤツの死体を俺は荒野で見つめてきたよ。
逆に言やぁ、利益率が派手じゃなくても、安定して現金が残り、借入が減り、内部留保が積み上がってる会社...そういうヤツは強ぇんだ。地味だが、荒野で最後まで立ってるのはいつもこのタイプだぜ。
売上より利益、利益よりキャッシュ
売上は規模を見せる。粗利は収益構造を見せる。営業利益は本業の採算を見せる。税引後利益は会計上の成果を見せる。
だがな、商売を続ける力を最もストレートに示すのは、最後に残った現金だ。
売上が伸びてるから安心？黒字だから自由に使える？...甘ぇよ。
税金を払い、借金を返し、必要な投資をした後にも現金が残る。その現金を蓄え、再投資し、不測の事態に備える。それが長くサヴァイブするための基礎だ。
華やかな売上や高い粗利率より、最後にいくら残ったか。経営計画はそこから始めろ。
アディオスアミーゴ。メヒコのビーチで残りの弾を数えてくるぜ。また会おう、生きてたらな。
