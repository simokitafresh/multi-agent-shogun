# 開業医が毎月100万円をインデックス投資にぶち込むとどうなるか？

<!-- key=n65bb2d864483 publish_at=2024-11-08T15:19:54.000+09:00 price=100 full=True like=22 -->

インデックス投資は入金力のゲームです。
できる限り早くに、できる限り多く資金を投下し、できる限り長く続ける。
現実でお金を沢山持っている人だけが勝つ「勝者のゲーム」ですが、稼ぎのよいウハクリ開業医が毎月100万円をインデックス投資にぶち込むとどうなるでしょうか？
任天堂の倒し方は知りませんが、入金力100万レベルの開業医の倒し方なら知っています。
まずモデルプランの結果を提示し、その後に世間一般でよく想像される複利プランを提示します。
そしてどうやって倒すか、倒すのに必要な力が何かを具体的に提示していきます。
