# 医師だけが直面する二重累進課税という名の悪意

<!-- key=nd4737278102d publish_at=2025-10-05T11:12:45.000+09:00 price=0 full=True like=17 -->

ヤーマン、今日も生きてるか？今日は日本の医者どもが直面してる「二重累進課税」って地獄について話そうぜ。俺はバムだ。ひでぇ話になるぞ、そこに座ってラムコークでも飲みながら聞いてくれ。

街のイーンフルエンサーは「医者は高収入だから税金払って当然！」なんて叫んでるが、そいつらは何も分かっちゃいねぇ。医者ってのは、この荒野で二重にゾンビの群れに襲撃されてる特殊な狩人なんだよ。
一重目の襲撃：現金納税の累進地獄
まず最初の襲撃を説明してやる。これは普通の税金、つまり現金で払う方のゾンビどもだ。
医者は「高所得層」ってレッテルを貼られて、所得税と住民税で限界税率が跳ね上がる。50〜60％ってレベルだ。稼げば稼ぐほど、国家ってゾンビの大群が懐に手を突っ込んでくる。
でもな、ここで気をつけろ。医者の所得ってのは「資本による所得」じゃねぇ。株とか不動産みたいに寝てても入ってくる金じゃない。これは「命と時間の切り売り」で得た金なんだよ。
...おっと、コークが空になったな。もう一杯どうだ？
つまりだ、医者は自分の時間と健康を削って稼いだ金を、まるで金持ちの不労所得みてぇに課税されてる。これが第一の罠だ。
二重目の襲撃：現物納税の累進地獄
ここからが本番だぜ。お前、「現物納税」って概念を知ってるか？
街のイーンフルエンサーどもは誰もこれについて語らねぇが、医者ってのは金だけじゃなく、「労働そのもの」を国家に納めてる。これが二重目のゾンビの群れだ。
具体的に何のことか？簡単な話さ：
診療報酬の価格統制 - 国が勝手に「この治療は○○円」って決めやがる。まるで獲物の値段を国が一方的に決めるようなもんだ

地域医療の義務的従事 - 採算取れない僻地でも働けってことさ。ゾンビだらけのエリアに無理やり派遣されるようなもんだ

救急・夜間当直の強制 - 24時間365日、いつでも駆けつけろってな。休息なんてねぇ

長時間労働の法的容認 - 他の職業なら過労死ラインの2倍、年間1860時間まで働かせられる

これが何を意味するか分かるか？
医者は時間と命を「現物」で国家に納税してるんだよ。
累進性の恐怖：能力が高いほど搾取される
ここからが一番ヤバい部分だ。この「現物納税」にも累進性がある。
普通の累進課税は「収入が多いほど税率が上がる」ってやつだろ？でも医者の場合、能力・責任・専門性が高いほど、より多くの時間と技能を納めなきゃならねぇ構造になってる。
優秀な外科医ほど難しい手術を任される。経験豊富な医者ほど緊急対応を求められる。責任感が強い医者ほど、患者のために無理をする。
これはまるで「強いヤツほど、より危険なゾンビの群れと戦わされる」ようなもんだ。しかも対価はほとんど変わらねぇ。
...ウイスキーのおかわりはそこにあるぜ。この話は長くなるからな。
ダブルバインドの悪循環
ここで整理してやる。医者が直面してる二重累進課税の構造だ：

現金納税 
所得に応じた累進税＋社会保険料
高所得層として高税率負担 

現物納税 
能力・責任に応じた累進労働 
時間・健康・家庭を犠牲にする負担 

合成効果 
働けば働くほど税も負担も増す 
高負担→過労→離職→医療崩壊 
分かるか？これは完璧な罠なんだよ。
医者が一生懸命働く → 収入が上がる → 現金税が増える → 同時に、能力が評価されてより過酷な現場に送られる → 現物納税も増える → 疲弊する → でも辞められない（患者がいるから）
まるで「走れば走るほどゾンビの群れが増える荒野」みてぇなもんだ。
制度的矛盾：公務員との比較
街のイーンフルエンサーは「医者は高給取り！」って騒ぐが、同じ公的セクターの公務員と比べてみろよ：
公務員（役所の職員）
時間労働規制がちゃんとある

残業上限が厳格に守られる

昇進すれば給与も上がり、負担も減る

「現物納税」は制度内で評価として還元される

医者
長時間労働が法的に容認される（1860時間特例）

過労死ラインの2倍働ける

責任と労働量だけが増え続ける

「現物納税」が対価なしの公的奉仕として吸収される

これのどこが公平なんだ？医者は「公的医療制度の末端執行者」として、ただ働きを強制されてるだけじゃねぇか。
荒野のサヴァイブ戦略
じゃあどうすりゃいいのか？医者のお前らに言っとくぜ。
1. 制度の罠を認識しろ
まず、お前が二重課税されてるって事実を認めることだ。「医者だから仕方ない」なんて諦めるな。この荒野の構造を理解するのが第一歩だ。
2. 時間の価値を守れ
現物納税を減らす方法を考えろ。無制限に働くな。お前の時間と命には価値がある。ゾンビの群れに囲まれても、弾薬（体力）は取っておけ。
3. 声を上げろ
一人で戦うな。同じ荒野で戦ってる仲間と連携しろ。制度を変えるには、サバイバーたちが団結するしかねぇ。
4. 出口戦略を持て
この荒野で一生戦い続けるのか？それとも別の道を探すのか？常に選択肢を持っておけ。逃げ道のない戦いは死を意味する。
最後に
お前が医者なら、この二重累進課税の地獄を生き抜くのは容易じゃねぇ。でも、構造を理解すれば対策も見えてくる。
街のイーンフルエンサーが「医者は恵まれてる」なんて言ってる間に、本当のサバイバーは冷静に自分の立ち位置を分析して、次の一手を考えてる。
この荒野で最後まで生き残るのは、文句を言うだけのヤツでも、諦めて受け入れるだけのヤツでもねぇ。構造を理解して、賢く立ち回れるヤツだ。
アディオスアミーゴ。メヒコのビーチで医療制度の歪みについて考えてくるぜ。また会おう、生きてたらな。
...おっと、最後にもう一つ。この二重課税の問題は、医者だけの問題じゃねぇ。医療が崩壊すれば、困るのは国民全員だ。今のうちに声を上げとかねぇと、いつかお前が病院に駆け込んだ時、そこには誰もいねぇかもしれねぇぜ。
ここに蜘蛛の糸がある。いますぐ昇り始めろ。
文句は昇ってから言えばいい。

死にたくなきゃ、こいつも聴いておけ。
