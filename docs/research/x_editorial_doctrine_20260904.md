# X 運用の編集方針(殿裁定 2026-09-04 12:42) — 正本

> 殿の言葉を要約せず、判断の根拠になる形で保存する。設計書 §16・system_prompt_v5・slot_calendar・stock_ledger・gate はこの文書から派生する。

## 最終ゴール

X アカウントを「DM-Signal を売るアカウント」から「**投資を数学・確率・検証で考える人のアカウント。その人が作っているものが DM-Signal**」へ転換する。

理想の順序: 面白い投資・数学・検証の話をしている人をフォローしていたら、その人が異常なほど検証した投資システムを作っていた。

## 読者に持たせたい認識(8 つ)

1. デュアルモメンタム投資そのものは合理的で面白い
2. この発信者は投資を雰囲気ではなく検証と数学で考えている
3. 都合のいい結果だけを見せる人ではなく、疑って検証する人だ
4. フォローすると投資・確率・数学・検証について有益な情報が得られる
5. 検証のない投資システムは信用しにくい
6. DM-Signal は「情報商材的な売り物」ではなく、継続的な検証の上に作られたシステムに見える
7. DM-Signal は実際にかなり儲かりそうだ、と読者自身に感じさせる
8. インデックス投資は優れた資産形成法だが、資本格差を逆転する装置ではない、という現実も考えさせる

## 心理遷移(投稿を読み続けた結果として起こす)

この人はちゃんと調べる → 普通そこまでやるか、というレベルで疑って検証する → 失敗した実験も隠さない → その思想で DM-Signal を作っている → これは普通の情報商材とは違いそうだ → しかも成績も強そうだ → フォローしておこう

「DM-Signal は信用してください」と直接言うことではない。

## 現行方針の問題(殿の診断)

投稿案がデュアルモメンタムの説明・DM-Signal の使い方・Basic/有料プラン説明・月次運用説明に寄りすぎ、「商品の公式アカウント」に見える。今後は DM-Signal を主語にしすぎない。

## 投稿比率(初期案、固定ルールではない)

- 80%: 投資・数学・確率・検証・デュアルモメンタム(分類 1〜5、7)
- 15%: DM-Signal の検証結果・実績・設計思想(分類 6)
- 5%: 直接的な DM-Signal 誘導

「売り込み投稿が中心になること」は避ける。

## トーン

- インデックス投資を馬鹿にしない
- デュアルモメンタムを神格化しない
- 数字は徹底的に疑う
- 自信はあるが、宣伝臭くしない
- 投資初心者にも分かるが、知的に薄くしない
- 無難な企業公式アカウント文体にしない
- 「誰が言っているか」が伝わる文章にする
- 発信者の知的態度が見えるようにする
- 断定できるところは断定する
- 過剰な免責・広告文・営業文句を避ける

**ブランドの 3 原則**: (1) インデックスを馬鹿にしない (2) デュアルモメンタムを神格化しない (3) 数字だけは徹底的に疑う

## 禁止

- DM-Signal を毎回主語にする
- Basic プラン説明を頻発する
- 「月 1 回見るだけ」など同じ利便性訴求の連打
- 公式アカウント風の無難な説明文
- 根拠のない「儲かる」
- 検証していない数値や主張
- インデックス投資を雑に否定する
- 情報商材批判だけを前面に出す
- 過剰な煽り

## 直接 DM-Signal を出す投稿の見せ方

商品紹介ではなく「この検証思想の実装が DM-Signal」という見せ方に寄せる。
