## 最終ゴール

X アカウントを「DM-Signal を売るアカウント」から「**投資を数学・確率・検証で考える人のアカウント。その人が作っているものが DM-Signal**」へ転換する。

理想の順序: 面白い投資・数学・検証の話をしている人をフォローしていたら、その人が異常なほど検証した投資システムを作っていた。

## 読者に持たせたい認識(8 つ)

1. デュアルモメンタム投資そのものは合理的で面白い
2. この発信者は投資を雰囲気ではなく検証と数学で考えている
3. 都合のいい結果だけを見せる人ではなく、疑って検証する人だ
4. フォローすると投資・確率・数学・検証について有益な情報が得られる
5. 検証のない投資システムは信用しにくい
6. DM-Signal は「情報商材的な売り物」ではなく、継続的な検証の上に作られたシステムに見える
7. DM-Signal は実際にかなり儲かりそうだ、と読者自身に感じさせる
8. インデックス投資は優れた資産形成法だが、資本格差を逆転する装置ではない、という現実も考えさせる

## 心理遷移(投稿を読み続けた結果として起こす)

この人はちゃんと調べる → 普通そこまでやるか、というレベルで疑って検証する → 失敗した実験も隠さない → その思想で DM-Signal を作っている → これは普通の情報商材とは違いそうだ → しかも成績も強そうだ → フォローしておこう

「DM-Signal は信用してください」と直接言うことではない。

## 追記 2026-09-04 14:38 殿裁定「少し荒い方が隙が出来てプラス」

X 投稿を数学論文や完全な解説文にしない。正確性は守るが、考えられる条件・例外・反論を本文で全て潰さない。読者が「いや、それはこうでは？」「比率では？」「この条件なら？」と一言入れられる余白を意図的に残す。誤情報を出すという意味ではない。

- NG(Fact gate で止める): 事実誤認/数学的に間違い/存在しない数字/検証していない数字/因果の捏造/元資料と反対の結論/読者を誤認させる重要条件の隠蔽
- OK(Voice として許容): 全条件を書かない/自明な前提を省く/厳密な定義を毎回書かない/例外を全部列挙しない/説明を途中で止める/強めに言い切る/反論可能な主張を置く/詳細をリプで説明できる余白/読者が補足したくなる程度の粗さ
- **Fact correctness と Explanation completeness は別物。正しいことを書く必要はあるが、正しいことを全部書く必要はない。**「正しい核だけ置いて、全部説明しない」を許容する。
- 例: NG「同一利回り・追加投資なしという条件下では、初期資本1000万円と1億円の相対比率は30年後も10倍であり、絶対額としての資産格差は拡大する。」(数学的に丁寧だが X として死んでいる) / OK「平均を狙っても、格差は縮まらない。1千万と1億の差は30年後は拡大する。」→リプ「比率は10倍のままでは？」→「そう。比率は10倍のまま。だから縮まってないんよ。」この余白は欠陥ではなく会話の入口。
- **conversation gap** = 読者が質問・補足・反論・引用をしたくなる余白。良い gap: 核は正しい/単独で意味は通る/説明を完結させすぎない/一段深く考えられる/リプで追加説明できる/知識不足には見えない。悪い gap: 単なる間違い/意味不明/前提不足で結論が変わる/誤解させる/数字が間違い。混同しない。
- **Fact gate と Voice gate を分離**: Fact gate=嘘・数学的誤り・未確認数字・重要な誤認を止める。Voice gate=説明しすぎ・優等生化・論文調・LLM 調を止める。Fact gate を厳しくしても Voice を堅くしない。「正確性を上げる」≠「文章を長くして条件を全部書く」。
- system prompt は大改造しない。v5.2 程度の小変更(conversation gap/fact≠completeness/説明しすぎ禁止/リプで二段目/Fact・Voice 分離)。human rewrite few-shot を最優先。
- 評価軸: 1 Fact correctness/2 Voice match/3 Intellectual value/4 Conversation gap/5 Over-explanation(高いほど悪い)/6 LLM polish(高いほど悪い)。
- 投稿を完成させすぎない(導入・説明・例・反論処理・結論・締めを毎回入れない)。疑問だけ/主張だけ/数字だけ/違和感だけ/結論だけでもよい。本人 X に実在する型を優先。
- リプをコンテンツの二段目とする(投稿=核・違和感・数字→読者の質問→本人の一段深い説明)。想定リプを内部で 1〜2 個持って評価してよいが本文に書かない。
- KPI との関係: conversation gap が本当にプラスかは仮説。replies/quotes/bookmarks/profile visits/follows で forward test。「荒い方が伸びる」と決めつけない。
