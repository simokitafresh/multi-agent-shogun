## §0 真因(一本)

第一段階B1-B49の検知器系欠陥は全て同じ一点に落ちる:

**検知器は、自分の間違いを誰にも検知されない唯一の存在である。**

コードには検知器が付いたが、検知器自身は作りっぱなし — 既知の陽性を検出できる証明も、既知の陰性を通す証明も、一度も要求されていない。写し比較(A1)も、黙る検知器(A8)も、到達しないコード(A10)も、residual_bp=0の嘘も、全てこの一点の現れ。

## §1 構造型(一本)

**既知の陽性1件を検出し、既知の陰性1件を通すことをCIで毎回証明できない検知器は、存在してはならない(対照fixture必須)。**

これが10問を包含する理由:
- 写しを見る検知器 → 実体を変えた陽性fixtureが検出できず落ちる(A1/A4)
- 到達しないコード → 対照が通らず落ちる(A10/A2)
- 黙る検知器 → 陽性対照を書けない事実自体が露見する(A8)
- 出口なし/合成デッドロック → 陰性対照(正常系が通ること)が落ちる(A3/A6/A7)
- 検知器が増えるたび対照も増える = 自己検証構造。パターン数に依存しない

**運用補足(2026-07-26 15:18、小太郎の第1弾実証で確定)**: 「陽性1+陰性1」の定義だけでは足りない2点を全弾のACへ含める:
1. **先にexit 0へ至る経路を数える** — 出口が複数ある検知器(実例: stop_session_alertsは3経路、うち1つは問題が残ったまま通すbypass)で経路を数えずに陰性を書くと、逆の不変量(「TODOが残っていても通すのが正常」)をテストへ固定する
2. **変異試験で対照が空でないことを示す** — 検出条件を殺して陽性がnot ok、常時発火に変えて陰性がnot okを両方向確認(vacuousな対照の排除)

## §2 工程(監査ではなく機械作業)

1. **機械列挙**: 全検知器(gates 62+hooks 46+githooks 3=111+台帳consumer)について「対照fixtureの有無」を機械判定(tests/配下に当該検知器の陽性+陰性テストが実在するか)。10問の人手監査はしない
2. **対照を書く**: 無い検知器へ陽性1+陰性1のfixtureを書く(1検知器=1小弾、idle忍者へreflux配備)
3. **書けなければ削除**: 陽性対照が書けない=何を検出するのか誰も言えない検知器。LG051原則で削除
4. 先行して P2-0b(D001-D009の3重実装統一等、同目的多重実装の正本統一)のみ残す — 対照を書く前に正本を1つにしないと「直したのに効かない」が再発するため
5. **セーブポイント(殿厳命2026-07-26 15:39-15:41)**: 46弾を段階(10弾前後のバッチ)に区切り、各段階のクローズ時に**その時点までの累積対照fixture全数+過去の不再現fixture群(B26/27/28/33等)を一括実行**し、全PASSを確認してセーブポイントとして記録してから次段階へ進む。直後の検証1回=点の検証、セーブポイント=面の検証(過去に見つけた問題が全て再現しないことの全数証明)。これを省くと「修正が新たなバグを生み、その修正がまた新たなバグを生む」連鎖を検出できない

## §3 監査者(実装者)の規律 — v2.1から継承(実証済みのため)

- **教訓の逆説**: 過去の教訓とパターンが一致したときこそ確認が薄くなる。発見の感覚が来たら「当てはまらない可能性を1つ挙げてから報告」
- **打ち切りの誤認**: 末尾の未完了区間を事象の終端と数えない
- **AC仮説汚染**: ACの選択肢を閉じない(2択なら第3を問う)。draftレビュー最優先項目
- 値と出所を対で書く / 範囲外へ結論しない / 既存で足りるなら教訓を増やさない

## §4 可搬の初実証(変更なし)

対象=dividend-tracker(検知器0件を実測確認済み)。可搬の定義=**無い所に作れること**。証拠3点: ①report gateの両方向動作 ②lesson登録→task注入の還流一周 ③検知器を1つ設置し、それが§1の対照fixtureを持つことを示す(0→1の設置自体が実証)。1日以内・忍者1名。

## §5 完了条件(二値)

1. 対照fixtureなし検知器の件数が毎週減少し続ける(機械列挙で計測、新台帳なし=既存loop_ledgerチャネル)
2. 新設検知器は対照fixtureなしでcommitできない(CI/pre-commitで構造強制 — これ自体が§1を満たす検知器として対照を持つ)
3. §4の証拠3点の実証跡
4. 陽性対照を書けず削除された検知器は削除理由1行が記録される
